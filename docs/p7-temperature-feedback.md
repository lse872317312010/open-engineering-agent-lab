# 绕组温度—电阻—铜耗的双向仿真接口

2026-11-08。[先行契约](p7-temperature-feedback-contract.md)先提交为6811fa13。
原单向回放已推进为显式分区闭环：实际FOC积分铜耗 → 热更新 → 绕组均温 →
下一窗口电阻 → 下一段电气与机械积分。热ROM、源形状、电磁拟合与PI增益未重拟合。

新运行时位于src/oeal/stator_feedback.py，只需要NumPy及标准库。
StatorCopperFeedback接收驱动时钟tick和累计铜耗能量，严格一次接受一个完整窗口。
它先在候选热状态中预测，检查功率域和电阻温度域后提交；任何拒绝保留上次已接受状态。
返回的温度和电阻用于下一窗，CSV同时保存本窗applied_r与下一窗next_r以便审计。

合成定律为R(Tw)=0.3[1+0.004(Tw−25)]Ω，Tw限制0–125°C。
25/75°C环境下初始电阻分别0.3/0.36Ω，初始温度等于环境。
线性定常热材料允许以环境为温升零点平移，75°C工况只平移两路温度输出50K；
储热与外流能量仍计算相对环境的增量，不把初始50K偏置当成本次注入热量。

四组正反转/环境工况各运行独立ROM闭环和全阶热闭环，均为50ms。
两条轨迹各自积分电气/机械状态、PI、铜耗和电阻，比较也包含反馈造成的源差异。
75°C正向另有DOP853逐控制命令回放，以及电气/热窗同时减半的细化。
原始控制CSV、热窗CSV、全场/四输出NPZ、图、源码SHA及manifest独立归档。

联合能量余额将铜耗作为电气到热域的内部传递：

```text
输入电能 − 摩擦功 − 负载功 − 磁/动能变化 − 热储能 − 散热
```

各域也保留独立能量账；联合余额中再扣一次铜耗会造成重复计算。
窗口源能与电驱累计铜耗直接相连，不再读取预制铜耗波形。

先完成同几何FE、两版ROM冻结与验证，再运行：

```bash
python benchmarks/p7_temperature_feedback.py
```

输出位于outputs/p7-temperature-feedback/。预算以先行契约为准，失败返回非零。
该原型只覆盖微小自热的50ms离散仿真；尚未验证持续电驱、强温升反馈、热保护策略、
温度相关材料/磁参数、真实热边界或硬实时。环境初温差造成的电阻变化与运行自热反馈分别记录。
