# P8：高保真电机磁图、控制虚拟实验与精度闭环

更新日期：2026-11-17。P8 的目标是在明确模型和数据有效域内，把外部电磁求解器导出的模型用于控制联合仿真和算法优化。目标是对声明范围内的电机控制虚拟实验达到可审计的工程质量；这不等于替代 ANSYS Maxwell、JMAG 等通用电磁有限元软件的几何建模、网格生成与场求解能力。

## 近期实际结果

[2026-11-18：公开测量磁图空间留出与上游控制联合实验](p8-motor-progress-2026-11-18.md)。该实验的空间留出误差较大，不能认定 P8 磁图精度 Gate 通过。

## 当前基线（已合并）

PR #75 已把上游 motulator 0.25.0 接入主线，以公开 THOR/SyR-e 磁链表运行饱和同步电机、离散控制、MTPA/MTPV 特性图和 Optuna 参数搜索。电机方程、数值积分、控制算法和磁图插值由上游库提供。当前实验与证据见[入口说明](open-motor-model.md)和[实现契约](open-motor-model-contract.md)。

该基线还暴露了需要优先解决的精度边界：

- THOR/SyR-e 基线使用结构化 MAT。[外部点表流程](p8-external-fit.md)把 CSV 分组结果交给 GradNet 拟合，拟合和最终留出通过后可运行[受保护控制仿真](p8-external-guarded-drive.md)。实际厂商导出约定与目标电机精度仍待独立验证。
- 上游 512×512 反向磁链网格覆盖 57,220/131,072 个源点（43.66%）。768 网格在同一可比较子集上改善了电流重建最大差，但转矩误差没有改善、有效域没有扩大；这是事后诊断，不是独立留出验证。
- 当前示例的 Optuna 选择等于固定基线，尚未证明优化效果。
- 没有可靠的损耗、温度、角度谐波和独立实测/商业参考数据，因而不能声称完整效率、转矩脉动或商业软件等效精度。

不得用“更细的逆网格”替代覆盖域检查、数据留出或独立精度证据。

## 复用边界与依赖

| 能力 | 采用的上游 | 本项目职责 |
|---|---|---|
| 饱和电机、驱动控制、积分器、MTPA/MTPV 和机特性图 | [motulator 0.25.0](https://github.com/Aalto-Electric-Drives/motulator/tree/v0.25.0)（现有固定依赖） | 传入经记录的模型和工况；保存结果及证据 |
| 磁链/电流图的结构化拟合、角度谐波和留出误差分析 | [motulator-gradnet 0.1.8](https://github.com/Aalto-Electric-Drives/motulator-gradnet/tree/940d3b2daf3abd3ecca157f93cf4cc5363f5bb80)，MIT（已接入公开样本实验，非通用模型验收） | 使用上游训练与 NumPy 推理；公开样本的空间留出误差仍较大，真实用户模型尚未验证 |
| 控制参数搜索 | [Optuna 4.5.0](https://optuna.org/)（现有固定依赖） | 定义冻结的目标函数、工况分组和报告，不另造优化器 |
| 求解器软件导出 | 软件原生 CSV/表格/NPZ 等开放导出 | 仅编写格式、单位与坐标适配；不写商业软件私有二进制解析器或 FE 求解器 |

motulator-gradnet 上游说明：GradNet 由标量磁能/共能函数的梯度构成，可利用结构约束表示保守磁图；训练可用有限元或测量数据并支持空间谐波，官方示例以补集数据报告磁图误差。其 Python 项目要求 3.12+，训练依赖 PyTorch；训练后保存的模型可由 motulator 的 NumPy 接口评估，不必把 PyTorch 加入仿真运行时。物理正确性仍取决于源数据、覆盖域、拟合与独立验证，网络结构本身不构成精度证明。论文与实现说明见[上游文档](https://github.com/Aalto-Electric-Drives/motulator-gradnet)及[Li 等（2026）](https://arxiv.org/abs/2602.14947)。

P8 继续遵守“项目不造轮子”：不自写电磁有限元求解器、磁图插值/拟合算法、积分器、FOC、MTPA/MTPV 或超参数优化器。自有代码限于输入适配、单位/元数据校验、工作流编排、结果审计和可视化；若上游不能满足明确需求，应评估其他成熟开源库并记录差距，不悄悄重写算法。

## 外部模型交换约定

第一阶段不承诺直接读取所有厂商项目文件。用户从电磁软件导出可公开读取的点表，薄适配器再映射到上游支持的数据表示。优先覆盖的磁图列为：

- 必需：**id_A**、**iq_A**、**psi_d_Wb**、**psi_q_Wb**；可带 **torque_Nm**。
- 角度相关数据：**angle_rad**、**angle_kind**、角度周期和 **torque_Nm**；输入要明确电角/机械角及极对数关系。缺少这些字段时不生成角度谐波或转矩脉动结论。
- 可选损耗：分别标明工况、温度和算法来源的铜损、铁损/附加损耗等；没有完整所需损耗图时，不发布效率图。
- 元数据：源软件/版本、模型及导出 SHA-256、单位、dq 轴/相序、峰值或 RMS、电机极对数、温度、叠长/基值、网格或求解设置、模型版本和有效域。
- 所有输入数组须保持源文件身份与原始单位。转换后的每个字段记录变换、单位与来源；缺失值、重复坐标、无效点和域外数据显式标记，不静默补点或外推。

可先提供 CSV + JSON 元数据侧车，再由薄适配器生成 motulator-gradnet 要求的 NPZ 表示（上游示例使用 i_s_dq 与 psi_s_dq，角度谐波数据还带角度/转矩字段）。具体列、符号与峰值/RMS 约定须以用户的实际导出文件为准；未经确认不得推断坐标含义。若源数据不规则或存在无效区，只能把有效训练点交给适配层，不把矩形网格边界误作物理有效边界。

## 必须生成的电机特性图

按数据存在情况分级显示“可用 / 缺数据 / 超出有效域”，不能留空后让用户误以为模型计算正常：

1. ψd、ψq 对 id、iq 磁链面及源点/留出点/残差热图。
2. 源转矩及模型转矩对 id、iq；角度数据可用时再给转矩—转角、谐波与脉动。
3. 差分电感矩阵 Ldd、Ldq、Lqd、Lqq 或上游模型能提供的等价增量磁特性，并标明提取方法。
4. MTPA、MTPV、恒转矩线、母线电压/电流限制及转矩—转速/功率包络。
5. 反电势/电压裕度图仅在磁链及转速域足以支撑时生成。
6. 效率图仅在电机损耗数据完整并经过留出验证后生成；本项目当前采用理想平均逆变器，因此不包含器件导通、死区和开关损耗，不能称为包含逆变器损耗的系统效率。

每个图都要显示轴标签、单位、工况温度、有效域边界、源数据/拟合/留出图例以及数据不足状态。交互报告需适配桌面与窄屏，允许选择工况、显示模块运行状态、缩放/悬停查看数值，并提供输入、配置、图表数据和仿真轨迹的可追溯下载。

## 精度闭环与验收 Gate

错误预算必须在查看结果前按目标电机和用途登记，至少分别针对磁链、转矩、增量电感、边界/电压裕度及优化后的时域响应。以额定量或明确的物理量范围归一化；零附近量同时报告有单位的绝对误差，不使用无定义的相对误差。不得从一个综合分数掩盖单项失败。

| 子 Gate | 验收要点 |
|---|---|
| **P8-A 输入可信** | 原始文件可复现且有 SHA；单位、坐标、极对数、温度、数据来源和有效域完整；错误格式/字段拒绝，不静默猜测。 |
| **P8-B 磁图可信** | 对照原始数据和上游基准插值，按空间/角度/电流区域分组冻结训练、验证、最终留出；不得随机拆分相邻网格点造成泄漏。逐项报告 MAE、RMSE、P95、最大误差与归一化方式；梯度/互易性及源转矩一致性按适用模型核验；拟合和仿真域外状态明确拒绝或标记。 |
| **P8-C 特性图可信** | 在声明的电流、速度、母线和温度域内生成上述适用图；说明上游算法、边界约束和不支持项。仅从磁链图不能声称已得到可靠损耗/效率。 |
| **P8-D 控制联合虚拟实验** | 固定已有控制器和理想平均逆变器假设；冻结多工况目标函数，比较优化前基线、优化结果及留出工况。报告电流/转速/转矩误差、约束违反、搜索预算和退化案例。只有独立留出优于预先固定基线时，才写“改善”。 |
| **P8-E 独立参考** | 优先用未参与拟合的 FE 点、网格/角步细化数据或授权的测量数据做独立核验；商业软件比较只有在同几何、材料、边界、网格/求解条件与合法许可下执行。区分“复现源数据”“源求解收敛”“独立物理验证”三种证据。 |

P8 只有所有依赖 Gate 通过后才可宣称对应范围完成。有限元输入质量不足时应定位为“控制模型实验”，不能把控制仿真精确误差冒充物理模型精度。所有结论绑定源模型 SHA、上游版本、配置、脚本、运行环境和结果 SHA。

## 本项目与闭源工程软件的差距口径

当前已覆盖的是“一个公开磁图 → 饱和同步机/FOC 仿真 → MTPA/MTPV 图 → 小规模控制参数搜索”的可复现链路。要在这个垂直场景接近专业工程软件，还缺稳定的外部格式接入、受物理约束的磁图重构和独立验证、角度/温度/损耗扩展、全转速包络、可解释的多目标优化及易读报告。几何建模与高精度原生场求解仍由外部电磁软件完成。

因此，衡量追赶进度使用“通过 Gate 的模型种类、特性图、有效域、独立误差和可复现实验数”，不使用笼统百分比，也不以 CI 通过或图表数量推断闭源软件等效。
