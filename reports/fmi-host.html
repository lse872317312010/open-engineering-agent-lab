    来源与边界

    原创 MIT C 模型；FMPy 0.3.26 执行 FMI 2.0 加载与验证；SciPy DOP853 使用独立 Python 方程逐窗积分。FMU 包内保留源码、契约与许可证。二进制仅覆盖 Linux x86_64。

    本模型没有 MuJoCo 整机、位置环、六轴耦合、磁饱和、齿隙、开关 PWM、OpenModelica 或实测标定。独立原始证据保留全细步波形、失败案例、CLI/API 以及受保护 Agent 工具的检查结果。
