# P6 模型深化：开源模型实际接入与预声明验收

2026-10-23。继续遵守仿真验收，真机由用户负责。旧 P6 是平均电压、常电感、
理想反馈、研究双惯量和三节点热网络；旧 Gate 不代表这里新增的能力已完成。

## 本轮模型与来源

- motulator 固定提交 `2ffbf1ae52d5fadcdffd85d10c80dd15fd2e39fa`（MIT）：
  实际调用 SynchronousMachine、VoltageSourceConverter、CarrierComparison、DCBus、
  DiodeBridgeDCBus、TwoMassMechanicalSystem、Sensor 和 Simulation 的事件求解器。
  相量采用幅值不变坐标、峰值电流，SI 单位。
- 非线性磁图：同一提交的 `examples/drive/data/baldor_400rpm_map.npz`，
  Git blob SHA-1 `13205be7fd92362f6a3ed0178f7c1652f942fd64`。
  使用上游随包发布的测量来源示例图，不代表用户电机实测；
  线性切线和非线性模型必须使用同一台上游示例电机，不能和原研究电机混作精度结论。
- MuJoCo 3.3.7（Apache-2.0）；Menagerie UR5e 固定提交
  `cda5236f98383f6fbaa4820c6b18dba892cd087f`（模型 BSD-3-Clause）。
  复用上游完整连杆质量、质心、惯量、几何与关节参数。
  原位置执行器只保持其他轴；选定肩部轴以独立的电机—减速器力矩接口驱动。
  合成电机、弹性/齿隙和负载夹具不能被称为真实 UR5e 驱动器参数。
- 温度：新增六节点（绕组、铁心、壳体、MOS 等效结、板、散热器）RC 网络，
  接收电气结果的铜耗/铁耗和明确标注的器件损耗估计；
  短时运行温度反馈电阻，长时实验明确为损耗回放，不冒充完整长时 FOC。

## 必须保留的运行机制

20 kHz 单更新 PWM、一个控制周期计算延迟；事件定位死区、二极管续流和关断；
电容母线储能/负载扰动、整流供电；电流偏置/噪声、ADC 与编码器量化；
电机磁饱和与凸极性；机器人姿态相关重力与惯量、传动弹性和齿隙、外部接触；
记录实际电压/电流限幅、PI 积分、三相电流、转矩、母线能量和热源。
开关事件模型不宣称半导体寄生参数、反向恢复或 EMI 精度。

## 实现前固定的数值门槛

1. 线性堵转 RL 独立解析极限最大电流误差 < 1e-5 A（理想平均模型）。
2. 理想开关桥瞬时端口功率差 < 1e-8 W；死区时间非负、区间和与周期差 < 1e-12 s。
3. 负载电容母线阶跃与独立解析式误差 < 1e-5 V；母线电压保持正值。
4. UR5e 重力转矩与势能有限差分误差 < 1e-4 N·m；
   无接触正反动力学往返加速度误差 < 1e-7 rad/s²，质量矩阵正定。
5. 六节点热网络无热源保持环境平衡，能量平衡差 < 1e-8 W，
   矩阵指数与独立 DOP853 末温差 < 1e-6 K。
6. 联合仿真宏步减半：关节位置最大差 < 0.02 rad；
   所有状态、功率、接触力有限；指定接触场景必须实际出现接触。
7. 非线性图运行状态不可静默超域；报告磁链/电流域、覆盖率和插值误差，
   发生外推的结果明确拒绝或标注失败，不作为有效精度结果。
8. 运行质量与物理目标分开。参考电流尾段平均偏差目标 0.1 A，
   关节位置尾段偏差目标 0.03 rad；目标不达保留，禁止靠调整容差隐藏。
9. 报告显示实际后端、参数来源、采样/宏步、版本/哈希、模型差异与失败结果。
   浏览器检查新增曲线、状态/来源切换、离线导出和 390px 布局。

## 交付与限制

复现脚本、固定输入、上游许可证、CSV/JSON、中文交互报告、PDF 和图表。
本轮先深化单个关节及独立电气研究，六轴各自独立电机闭环、厂商标定磁图、
齿面接触有限元、器件级开关瞬态、传感器模拟前端和实机数据校准仍需后续工作。

## 接口与夹具说明

机器人联合仿真采用显式 Jacobi 宏步：电机和机器人各自保持上个交换点确定的
传动转矩，分别推进；界面是力矩/速度功率端口，精度由宏步减半验证。
0.25 s 为观察短时动态的固定窗口，位置目标未达不靠延长窗口或改变目标掩盖。
夹具场景为合成的预加载球面接触，初始几何重叠 0.01 m；接触峰值与该设置、
模型约束和求解器有关，不能解释为真实碰撞冲击力。
器件热源为声明参数下的压降、导通和切换能量估计；门极关闭时切换热源为零。
