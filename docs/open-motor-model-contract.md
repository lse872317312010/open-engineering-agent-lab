# 开源外部磁链模型联合实验：首个集成契约

2026-11-17。用户要求复用开源项目，不自行开发电机求解器、逆变器、控制算法或优化器。入口接受 motulator 原生 SyR-e MAT 格式，电机和工况参数另给 JSON；不得把示例参数用于其他电机。motulator 0.25.0（MIT，Python≥3.12）负责磁链表导入/反演、饱和电机、连续时间求解、离散电流/速度控制、MTPA/MTPV及图；Optuna负责候选参数搜索，工程代码只负责输入、编排、指标及结果归档。以项目官方THOR公开示例数据、原参数作首个可重复案例，记录上游提交及文件 Git blob ID。

逆变器采用 motulator 的默认 ZOH 开关周期平均模型，阈值电压0、无死区非线性；保留有限母线电压、调制限制与一个采样周期计算延迟，不能称为无限电压源。真实模型允许上传同格式数据，须另提供极对数、电阻、转动惯量、电流/电压等，并确认单位、坐标和相序；其它软件格式没有自动接入前不宣称已支持。默认导入会按上下文对负q轴作对称扩展；原数据缺少的空间谐波、温度、铁耗、机械损耗不自动生成。

冻结实验：仅以两种速度环带宽（2/4 Hz）和同一上游电流控制、机器模型分别运行；Optuna 网格搜索以规定训练工况的速度误差均方根排序；再对最优参数和固定4 Hz基线，在不同负载阶跃上分别重跑。保留全部指标及参数，不能预设改进；误差只说明所选仿真工况而不代表物理精度或安全。验证各轨迹结束成功、数值有限，提供输入SHA、工具版本、磁链dq二维图、上游MTPA/MTPV相关轨迹、速度/电流/电压/转矩时域图和可重放数据。

motulator 映射插值默认允许边界外线性外推；逐已保存端点检查反向磁链网格矩形包络、记录数量和范围，不以此声称内部所有积分点均受控。表覆盖不足、逆映射误差和越界需后续单独验证。没有真实铁耗或转矩—转速全工况数据时，效率图、齿槽/转矩脉动、动态FE对照与商业软件等效精度标记缺失，不捏造。独立商用/实测基准、空间角度相关特性和网格/时间收敛需单独完成。真机由用户负责。
