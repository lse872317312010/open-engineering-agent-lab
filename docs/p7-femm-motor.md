## 物理对象与运行机制

原创二维无槽两极模型，深度40 mm：半径20 mm的均匀磁化永磁圆柱，
20–22 mm空气隙，22–28 mm六个铜绕组扇区，28–40 mm线性定子背铁。
磁体Br=1.2 T、μr=1.05，背铁μr=1000，外圆Az=0。
六绕组每侧20匝，中心依次对应A+90°、B+210°、C+330°及其反向边。
峰值幅值不变Park采用2/3系数，功率采用3/2 dq内积；极对数p=1。

圆截面转子通过实际磁化方向旋转表示角度；没有滑移带或非圆形转子运动验证。
三档global h=1/.5/.25 mm、gap h=.25/.125/.0625 mm、
圆弧分段上限2/1/.5°。每档分别真实求解24角及48角开路，
±0.5 A的d/q载荷、三次单相1 A激励和±0.5°虚功位置，共81个算例。
三档合计243份fem输入和243份ans解文件，均保留。

从实际开路磁链基波提取ψ；±dq电流差分提取Ld/Lq；
相矩阵独立检查互易与正定。转矩对照包括FEMM加权应力、
空气隙21 mm圆周总场Maxwell应力积分和固定相电流的磁链虚功。
应力积分使用显式锁定的FEMM恢复B，每批同一Lua文件先设模式再读场；
原始单元B另存。两路应力与虚功共享FE解，不能当作独立求解器交叉验证。

## 独立参考与实际结果

先以有限圆域均匀磁化圆柱解析解核验FEMM及磁化方向：
磁体/空气μr=1、a=20 mm、R=40 mm，内场Bx=0.45 T。
三网格32个固定点误差下降，最细Az相对RMS为0.015716%，
B为0.089381%；反向磁化负例被拒绝。
另用源自由环域的解析Maxwell转矩极限测试符号、半径独立性和积分公式。
该极限只验证积分算法，不提供当前PMSM的解析转矩真值。

|---|---:|
| ψ | 0.026027778488130024 Wb |
| Ld | 31.30558393055205 μH |
| Lq | 31.30558683423915 μH |
| 中→细ψ相对变化 | 0.00004836% |
| 中→细Ld/Lq相对变化 | 约0.009572% |

三档恢复B的MST对加权应力差约4.96%、0.139%、2.475%，
**不单调**；最细原始B的对应差约1.30%–1.33%，比该档恢复B更小。
接受方法在新网格运行前冻结，不事后挑选误差最小的后处理。
各档沿用原5%转矩差、3%积分细化等门槛。
开路基波拟合很小的残差源于当前线性圆形模型，
不能解释成有槽/饱和电机预测精度；48角FFT只覆盖实际采样可见的谐波。

R=0.3 Ω、J=0.002 kg·m²、粘性摩擦=1e−5 N·m·s和p=1
为单独指定的合成系统参数；静态FE仅输出ψ/Ld/Lq。
不宣称已从绕组/端部几何提取电阻、转子质量惯量或损耗。
