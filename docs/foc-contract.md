# FOC 模型契约（P1-B）

新增实现以现有 dq 方程为基础。先声明符号与更新顺序，再以独立基准验收。

- 电角度 theta_e=p*theta_m；解耦电压 fd=-omega_e*Lq*iq，
  fq=omega_e*(Ld*id+psi_f)，单位 V，正负转速均适用。
- 控制器使用当前测量的 dq 电流、机械速度和角度。默认 Ts=50 us，
  参考在 t=1 ms 从 (0,0) 跳至 (0,5) A。
- 每个控制 tick：采样→前馈→PI/限幅/回算→逆 Park→平均 SVPWM→更新保持电压。
- 平均 SVPWM 先限幅到 Vdc/sqrt(3)，逆 Clarke 得相电压，
  注入 -(max+min)/2 共模，再计算 duty=0.5+phase/Vdc。
- **保持的是静止 alpha/beta 电压**，不是旋转 dq 电压。RK4 各子步重新用转子角度
  投影实际 dq 电压；每控制周期积分分段，不跨越控制更新事件。
- delay_samples=1 时，计算出的静止电压下一周期生效，首周期为零电压。
  回算使用控制器本次限幅结果，并非延迟执行器误差补偿。
- 此为理想平均逆变器，无 PWM 开关、死区、ADC 孔径或 ISR 抖动。
  120 kHz/20 kHz 的事件网格只表示排程语义，不构成开关精度或硬实时证据。
- 示例参数为合成研究值；惯量取 0.002 kg*m²，避免短时基准落入电压不可达区。
  默认增益按带宽 2000/s、Kp=L*bandwidth、Ki=R*bandwidth 构造，不能视为实机整定。
- 预声明 B1 验收：稳态 q 误差<=0.05 A、峰值超调<=0.5 A、
  2%调节时间<=5 ms、电压约束违反=0；B0 独立 DOP853 rtol=1e-12、
  atol=1e-13，原生状态对比容差 1e-5。步长收敛单独记录。
