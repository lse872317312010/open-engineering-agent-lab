# 同几何定子边界敏感性与22状态ROM

2026-11-06。[执行前固定契约](p7-stator-rom-contract.md)规定训练/留出和门槛。
上游为[同几何定子热场](p7-stator-thermal.md)，没有改变其材料、几何和原24例验收。

## 训练和实际范围

同一14566节点细网格，质量、原h=20算子重新装配与已有导出差为0。
新增外圆Robin参数h，每条轨迹保持常值。h=5/20/80各用600s加热、600s零源冷却
做训练与敏感性回放；热功率P0=0.109218W，来自原50ms铜耗均值。
这是长时预设热源回放，不是1200s电驱联合仿真。

三档同源FOM在加热/冷却末端均符合换热增强、绕组均温不增的预期。
质量加权POD只使用这三组快照；最多20个POD方向，加总能量和初始源响应方向，
最终22状态。训练完成后冻结推理包、离线重构基、训练数据及SHA。
独立验证进程使用h=12/40和新的分段热源；未利用这两组数据选择维数或拟合。

## 本地结果

| 指标 | h=12验证 | h=40留出 | 固定预算 |
|---|---:|---:|---:|
| 同1s BE全场最大节点差 | 83.60µK | 97.56µK | 100µK |
| 两均温各自RMSE的最大值 | 0.218µK | 0.263µK | 20µK |
| FOM 1/0.5s时间敏感性 | 40.45µK | 46.14µK | 100µK |
| 400Hz ROM对0.5s FOM均温最大差 | 19.47µK | 22.65µK | 100µK |

留出全场差接近门槛，余量较小；不扩大到任意局部热源、连续参数精度界或所有初态。
全场差是在同时间离散下相对于同一FE模型的误差，不是相对于实测的总误差。
400Hz均温差还包含FOM时间离散效应，不把其解释为纯降阶误差。
两组每组480000次真实状态更新、480001个端点，含完整四输出和源功率/能量余额。
四输出为绕组/铁芯均温、总储热、环境散热；全场重构是离线功能，计时中不包含它。

本地主机的计算预算记录以summary.json及5000个原始耗时样本为准。
最终本地回放p95=41.4µs、p50=19.2µs，最大188.5µs；
最大400Hz能量余额2.97e-9J，冻结包及推理实现身份校验通过。
完整测试342通过、23项可选依赖/资产检查跳过，Ruff通过。
模型按2.5ms数学时钟更新；这不是按墙钟调度的硬实时实验，也没有接入20kHz电流控制器。
推理API只依赖NumPy，独立子进程在禁止SciPy/Gmsh/scikit-fem/meshio导入时仍通过手算测试。
h=2/100和负/超限/非有限平均功率拒绝，不夹紧；非法输入不改状态。

## 复现和交付

在原定子热场工作流完成后，分别运行两个进程：

```bash
python benchmarks/p7_stator_rom_study.py train
python benchmarks/p7_stator_rom_study.py validate
python benchmarks/build_p7_stator_rom_figure.py
```

outputs/p7-stator-rom/包含inference.npz、offline-basis.npz、frozen.json、training.npz，
两个验证包（全400Hz输出、FOM输出与24s场快照）、逐样本计时、图和manifest。
API用法：

```python
from oeal.stator_rom import StatorThermalROM
model = StatorThermalROM.from_npz("inference.npz", h_w_m2_k=12., dt_s=.0025)
outputs = model.step_average(.1)  # 此2.5ms窗口的平均铜耗W，不能再平均一次
```

h域[5,80]、功率域[0,2P0]和冷初态被冻结；仅验证指定均匀槽绕组源形状、
固定合成热材料、边界与离散工况。材料/接触不确定性、真实传感器、端部和转子、
未知源、参数随时间变化、温度反馈以及板端期限均保留。完整Gate C/D仍未完成。
