# BDM1守恒通量后处理：实现前固定验收

2026-10-30，延续PR #39。保留全部P1/RT0实现、数据与门槛。
同Gmsh4.13.1/scikit-fem11.0.0/SciPy1.15.3，无新增依赖。

BDM1为scikit-fem ElementTriBDM1，二维三角形上完整仿射向量空间，
每facet两个法向DOF、单元散度为常值；原RT0只能表示a+b*x（b单标量）。
先用独立基函数张成性与边法向积分极限验证选型，再实现投影。

最小化1/2∫|q+k grad(T_P1)|²/k，逐单元约束∫div(q)=∫s。
原温度/网格不变，解析参考不得进入后处理函数。
上下法向为零；右边界来自同一原P1温度h*(T_P1-Ta)，
用实际BDM法向基函数的边L2质量矩阵投影，不假设DOF等于积分或密度。
RT0右边为面平均，BDM可保留线性分布；共同原温度来源相同，
但空间允许的边界表示不同，必须在报告中明确，不能声称仅改内部自由度。

固定三工况n8/16/32九组合及零源n8patch，与原RT0相同：
- 网格MSH hash/节点坐标对齐，原P1温度文件和数组前后hash不变；
- 独立几何单元余额/契约功率尺度<=1e-9；
- 两侧完整法向迹最大差<=1e-8W/m²，实际边积分与DOF矩向量乘积差<=1e-9W/m；
- 几何法向误差<=1e-12；原P1边界总功率变化/尺度<=1e-9；
  右边完整线性法向迹对h*(T_P1-Ta)误差<=1e-8W/m²，上下完整迹同样检查；
- 以独立几何关联审计翻转最大非零内部法向矩贡献的DOF副本，必须拒绝；
- 各组合BDM全域通量相对L2误差<=0.5*min(原P1,原RT0)；
  每工况三档BDM全域误差收敛阶>=1.5，最细相对误差<=0.005；
- 每工况最细界面实际逐高斯点（含facet内线性变化）加权RMS局部相对误差<=0.001，
  比原较差侧P1改善>=75%，界面均值局部误差<=0.01。
  不仅评价facet平均值；RT0与BDM的RMS均用同一局部解析幅值。
- 零源patch BDM全域通量相对L2<=1e-9，保留局部守恒；
  热环境右向外功率仍为负。
