## 显式改变算子，而不是让固定参数模型猜测

已有接触矩阵C在Rc=.1m²K/W时装配，故
K(Rc)=Kbulk+(.1/Rc)C，Kbulk=K(.1)−C。
采用同一冻结基底V投影M/Kbulk/C/F/物理输出，
参数改变时重组小矩阵，界面向右热流输出也乘.1/Rc。
不在不同基底之间插值坐标，也不插值温度预测。

仍为n32接触板：2178温度节点、2145自由状态，
Cv=1000/2000 J/(m³K)、k=2/.2 W/(mK)、h=10 W/(m²K)，初温/环境/恒温端25°C。
这些均为理想合成模型，除Rc及已声明源倍率外的条件固定。
本轮不允许一条轨迹中突然改变Rc，也未检验真实器件的接触参数。

独立控制点Rc=.01/.3/1从真实Gmsh物理标签直接调用原接触弱式装配，
与仿射矩阵的逐元素最大差均6.94e−18W/K，低于实现前门槛1e−11W/K。
这验证矩阵拆分、比例和坐标身份，不能替代全部物理场精度。

## 实际接口拒绝，不只是报告状态标签

新增[NumPy-only接口](../src/oeal/thermal_rom.py)：
`AffineThermalROM.from_npz(path, rc=..., dt_s=...)`。
从数值NPZ读取推理矩阵，不导入FE、SciPy或pyMOR，不读pickle；
基底/全阶数据不参与在线加载。
加载时验证格式版本、形状、有限性、当前质量/刚度对称正定，
复制矩阵为只读，Rc/dt必须为真实有限标量，bool不当作数值参数接受。

Rc声明计算范围为闭区间[.01,1]，dt∈(0,.1]；
范围允许计算，**精度仅证于所测离散工况，没有整个连续区间的误差界或统计可信度保证**。
该身份守卫也不是未知参数识别器。
固定材料/容量/环境/几何的来源仍由选用的模型文件确定，不自动感知外界物理条件。
模型加载校验数值格式，不认证模型来源；冻结来源可按随包SHA256清单核对。

每次step接收两个当前端点源倍率，范围[0,2]，内部与上次端点平均推进CN；
初态为u=0、上次源为0。接口管理状态，调用者管理时间。
非法输入在更新前拒绝，状态保持原值；state属性返回拷贝。

返回六元素依次为：
1. 材料一体积平均温度°C；
2. 材料二体积平均温度°C；
3. 界面左侧平均温度°C；
4. 界面右侧平均温度°C；
5. 界面向右功率W（负为向左）；
6. 右边界向外对流功率W（负为环境入热）。

```python
from oeal.thermal_rom import AffineThermalROM

rom = AffineThermalROM.from_npz("model/rom.npz", rc=0.07, dt_s=0.0025)
# 每次调用推进一次；此处给出当前端点源倍率，不要自行再做梯形平均。
temperatures_and_powers = rom.step([0.5, 1.0])
```

每对象Rc固定，重新创建对象会从初始平衡重启；
没有状态迁移、在线切换参数或传感器校正能力。
测试用对角系统的独立标量CN参考核对参数比例/输入平均/温度偏置和流向输出；
无效Rc/dt、格式/矩阵错误及拒绝时状态保持分别验证。
实际大模型step返回的六物理输出与独立全场物理审计逐时核对，最大差≤1e−9。

## 域外反事实：误差小也不事后扩大范围

Rc=.005和2在接口创建时实际抛出ValueError，
没有把它们当作可用推理实例。
另绕过公开守卫、使用冻结投影算子生成反事实以保留完整证据：
这两点节点峰差约6.87e−5和5.81e−6K，数值误差仍通过本轮精度门槛，
但accepted均false，范围保持实现前声明的[.01,1]。
不能据两个额外点就认定所有范围外参数可靠。

两反事实的完整FOM/参数ROM/原固定ROM数据在报告和原始包中保留，
界面和表格明确标为域外。精度、能量和接口许可分开，
不把“被拒绝”等同于“本次反事实误差必然很大”。
