# 规定电流包络下的长时热反馈

2026-11-08。[先行契约](p7-feedback-endurance-contract.md)先提交为0cceba31。
本增量补充长时热域证据：规定dq电流包络 → P=1.5R(Tw)|i|² → 热FE/ROM →
下一窗电阻。电流在窗内视作准确保持；它不求解该长时段的PI、PWM、电压或机械ODE。
实际FOC双向联动继续由[50ms专项](p7-temperature-feedback.md)提供证据。

三条轨迹均为24,000s（约6.67h），1s更新：A/B同为h=8、iq=0.5A恒流，
环境分别25/75°C；C为h=65、75°C，每1200s周期600s通电、600s零流。
全阶与冻结33状态ROM各自计算自己的温度、电阻、功率，分别推进闭环。
初始与环境同温、合成R(T)、空间源、材料与原功率上限保持。
新增current_envelope运行时复用严格热窗接口，暴露只读窗宽以确保能量积分使用实际窗宽。

每个1s端点流式比较全场，保存全部热输出、功率、电阻及源/散热/余额；
原始全场每120s保存一次（含初态共201组），不声称保存全部24,001个全场。
NPZ中outputs/fields/energy的模型轴按FE、ROM排序，能量列为源能、散热、余额。
power_w第n行用于第n个已完成窗口，resistance_ohm第n行用于下一窗口。
B另有0.5s全阶/ROM细化，以及前1200s的480,000次400Hz热更新。

稳态和稳定性采用单独的矩阵检查。设c=f为绕组均温观测/单位源，
a=1.5I²R(Tambient)，β=1.5I²R25α，则系统为：

```text
M dx/dt + (K − βffᵀ)x = af
z = K⁻¹f,  g = βfᵀz
x* = az/(1−g)
```

全阶K由已核验连通FE、正导热系数及外圆正Robin边界产生，为正定。
由K内积下的Cauchy–Schwarz，有
xᵀ(K−βffᵀ)x ≥ (1−g)xᵀKx，所以g<1给出该恒流线性热系统的稳定性条件。
当前显式一窗反馈/隐式导热更新的状态矩阵为
(M+ΔtK)⁻¹(M+Δtβffᵀ)，同一条件使其特征值处于(0,1)。
ROM另对Kr−βfrfrᵀ直接求解并检查最小特征值，避免只复用全阶稳态公式。
该条件适用于固定热算子、恒流与当前线性R(T)，不代表电流环或任意热保护策略的稳定裕度。

独立两节点手算覆盖显式反馈步进、源能与热能；小矩阵直接稳态解和独立谱半径检查
核对稳定条件，并验证不稳定反馈拒绝。非法/超功率电流包络拒绝不得改变热状态。
