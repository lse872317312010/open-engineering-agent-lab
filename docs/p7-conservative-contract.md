# P7守恒通量后处理：实现前冻结契约

2026-10-30，延续PR #38三工况×三网格和零源patch。
同Gmsh4.13.1/scikit-fem11/SciPy1.15.3固定环境，无新增依赖。
保留原P1温度、原梯度通量及全部门槛，不修改原解或以解析解修补通量。

## 方程与来源边界

q为热流密度W/m²，q=-k grad(T)，div(q)=s W/m³。
采用scikit-fem最低阶H(div) Raviart–Thomas元RT0
（上游ElementTriRT0是ElementTriRT1别名；不是RT1高阶元）。
原始未知量每facet一个有向法向通量积分，单位W/m，不含厚度。
求最小1/2 ∫ |q+k grad(T_P1)|²/k，约束每单元∫div(q)=∫s。
上下边界法向积分为0；右边界固定为原P1温度给出的
∫h(T_P1-Ta)ds；左恒温边界通量自由，通过局部守恒确定。
这是给定原温度/边界数据的约束后处理，不是独立温度求解器或第三方交叉验证。

后处理函数只接收实际网格、物理标签、原P1节点温度和公开k/s/h/Ta，
不得导入解析参考或调用真实通量。评价器在后处理后读取解析参考。
新网格MSH SHA256须与原P1网格相同，防止节点/单元编号错配；
原温度文件及数组在后处理前后hash不变。

## 固定验收

三工况n8/16/32九组均：
- 采用独立几何面积、facet到cell的有向关联，逐单元核验
  厚度*(Σfacet有向积分-s*面积)；最大单元余额/公开功率尺度<=1e-9。
  同时保留每单元相对自身源项（零源用全局尺度/单元数）的误差。
- 用实际RT基函数两侧迹检查内部法向通量，最大差<=1e-8 W/m²；
  基函数边积分应与保存DOF一致，误差<=1e-9 W/m。
- 右边界DOF来自P1边温，不读解析温度；边界总功率保持原P1，
  源与左右边界归一化余额<=1e-9，热环境的右向外功率仍为负。
- 翻转最大非零内部facet DOF的故障副本，独立几何余额必须拒绝，
  不能只用构造投影的同一div矩阵复核。
- 原P1温度、梯度及失败案例全部保留，不重命名为RT新温度。

三档全部记录全域通量L2误差（RT与原梯度）及界面逐段通量误差。
每工况RT通量L2误差每次收敛阶>=0.8，最细相对误差<=0.05。
每工况最细界面面积平均功率对解析值的局部相对误差<=0.01；
最细界面逐段密度加权RMS局部相对误差<=0.10，
且相对原左右梯度中较差的RMS改善>=75%。
原界面接近零仍按局部解析幅值评价并展示绝对值，不只用总功率掩盖。
零源n8补丁通量相对L2误差<=1e-9，逐单元守恒同上。
上述为预先门槛；失败保留，不根据结果放宽。
RT0精确法向连续是空间性质，不能单独算作预测准确的证据。
