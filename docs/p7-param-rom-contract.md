# P7 参数化接触ROM：实现前冻结契约

2026-11-02。固定板几何/容量/材料/边界下，增加每条轨迹恒定的Rc参数。
合成数值验证、部分P7-D，不是工程器件、连续域误差认证、时变接触或FOC同步。

## 方程与参数身份

复用已验收2178节点/2145自由状态模型，Mdu/dt+K(Rc)u=F a，
u=T−25°C。Rc面比热阻m²K/W，reference_rc=.1。
已有接触矩阵C是在Rc=.1时的装配；
Kbulk=K(.1)−C，K(Rc)=Kbulk+(.1/Rc)C。
同一真实接触法向输出也乘.1/Rc，不能只改K而沿用旧热流输出。
Cv/k/h/几何/初态/恒温25°C固定，两个区域体源仍为独立合成输入。
主IR/旧固定ROM不变，NumPy推理接口不依赖FE或pyMOR。

## 独立参照、训练和推理

训练Rc=.01/.1/1，各左右独立8s脉冲，共六条0–16s/dt=.05轨迹。
POD仅取每四个时间节点，486快照；pyMOR2026.1.1质量POD最多20模态，
先放左右区域自由节点指示向量，正交化后≤22维。
用同一V投影M/Kbulk/C/F/物理输出，不插值温度或不同基底坐标。
训练/拟合/评测分进程，训练和模型hash冻结后才生成验证和留出。
不依验证/留出选模态/边界/门槛。

独立装配控制点Rc=.01/.3/1：从Gmsh物理标签直接调用已验证接触弱式，
与仿射矩阵逐元素比较；最大绝对差≤1e−11 W/K。
接口小型对角系统解析CN参考在本契约同提交，核对Rc比例、输入梯形平均及输出偏置。

src/oeal/thermal_rom.py提供从冻结NPZ加载的NumPy-only推理对象：
创建时要求Rc在闭区间[.01,1]，dt∈(0,.1]；参数必须是真实有限标量，bool/NaN/非正拒绝。
输入为两个当前源倍率，均有限且在[0,2]，与上一步端点平均推进CN；
初始u=0/前一步输入0，返回六输出（四个绝对温度、界面/右对流功率）。
拒绝输入必须不改变状态。Rc对每对象/轨迹恒定；不是运行中无损换参数。
验证矩阵形状、有限性、对称正定及版本字段，数组复制为只读；
无任意代码/FMU加载，不宣称安全沙箱。

## 冻结评价矩阵

全部0–16s/dt=.025：
- validation-r.03 / validation-r.3：左幅1.2周期6，右幅.8周期4延迟1。
- holdout-r.02 / holdout-r.07 / holdout-r.2 / holdout-r.7：
  左幅.6周期2延迟.5，右幅1.5周期3延迟2。
- below-range Rc=.005 / above-range Rc=2：接口必须在创建时抛错；
  另用未守卫的投影算子保留反事实，不把它当作受支持预测。
同时保留上轮固定Rc=.1的14维ROM作为未守卫反事实基线。
域内可计算仅表示声明范围；精度证据覆盖本轮离散工况，不声称整个连续区间有误差界。

两区均温峰差≤.02K，界面向右功率峰差/.16W≤5%；
FOM和参数ROM全局/两区累计余额≤1e−8J。

Mr质量正交误差≤1e−9，Mr和各支持点Kr对称正定，维数≤22。
模型/训练hash前后不变，不要求原固定ROM全部失准或新模型达到固定提升倍数。
两域外均拒绝，允许反事实数值看似准确，仍不得事后扩大范围。

性能：实际公开step接口含输入校验、状态更新和六个绝对物理输出；
预计算分解/传播矩阵、100步预热/5000样本、dt=.0025，

宿主预算不等于固定周期/板端或FOC验证。
