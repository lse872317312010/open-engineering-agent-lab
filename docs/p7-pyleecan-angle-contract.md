## 输入与量纲

真实相电流abc均为0 A；机械角正方向与原已验证的转子坐标一致，
绝对机械角 = π/8 + 相对机械角。每次实际转角误差≤1e−12 rad，
原生深度由FEMM读取，磁链换算至50mm叠长并逐点对照库输出。
三档Kgeo/Kmesh=1、1.5、2各自完整求解相对0、7.5、…、82.5、90°，
共39个独立静态解；最后90°是独立闭合检查，导数不使用重复端点。
保留全部原生fem/ans、实际电流、网格、三相磁链、场采样、结果与SHA256清单。

实际角和转矩按原先契约；速度只是用于后处理的指定常数，
ωm=±600rpm及+1200rpm，单位rad/s。开路运动准静态假设下：
eabc(θ,ωm) = −ωm dλabc/dθm，λ单位Wb，角度单位rad，e单位V。
使用周期中心差分，12点间隔7.5°；6点15°取同一求解集合的偶数节点，
其导数仅用于角步敏感性比较。它们共享FE解，不是独立场求解器。

## 事前冻结检查

- 每例复用原单例的实际相电流、角度、面积、深度、MST和有限性门槛。
- 每网格磁链90°端点与0°向量差 / 0.05 Wb ≤ 0.02。
- 相同12角位置中、细网格磁链向量差 / 0.05 Wb ≤ 0.03；
  600rpm导出电压的中细差，以 |ωm|×4×0.05 Wb 标度，
  各相各角最大绝对差 ≤ 0.05。
- 中/细各网格12点对6点中心差分在共同角度的电压差，
  以相同固定标度，各相各角最大绝对差 ≤ 0.30；
  量测该离散差，不声称全角度连续误差上界。
- 细网格各相一电周期基波幅值均 >0.01 Wb；
  三相基波依次相隔±120°，相差误差各≤10°，并记录实际相序。
  零序可见，不强行归零。
- 逐点速度反向 e(−600)=−e(+600)、倍速 e(+1200)=2e(+600)，
  对电压标度归一后的最大差≤1e−12。该检查是后处理代数性质，非运动场验证。
- 原生解及源版本/输入哈希完整核验，缺点、重复点、非有限值、
  节点不递增和哈希不符均拒绝；失败不得事后放宽门槛。

独立解析测试：λa=sin(4θ), λb=cos(4θ), λc=−sin(4θ)，
角周期π/2、λ幅值1Wb，e=−ω dλ/dθ；
12点中心差分最大误差相对4|ω|≤0.046，6点≤0.174；
正负倍速、形状、非有限输入及不足三个点的拒绝必须测试。
