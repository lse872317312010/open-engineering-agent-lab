# 研发路线

## 阶段 0：可重复的研究仓库（当前）

- 独立 Python 包、PMSM dq 最小模型、样例输入、CSV/JSON 输出。
- 方程级测试、命令行测试、lint 和多 Python 版本 CI。
- 明确模型假设、单位、失效边界和 Agent 使用约定。

## 阶段 1：FOC 闭环与数值基准

- 增加 Clarke/Park、PI 电流环、解耦/反电势补偿和 SVPWM 平均模型。
- 定义采样与控制更新时序；加入饱和、抗积分饱和和电压/电流限制。
- 用解析 RL 响应、离散控制器边界案例和独立参考脚本验证误差。

## 阶段 2：关节模组和热模型

- 引入减速器/负载惯量、摩擦、传动误差以及绕组和功率板的热网络。
- 支持多工况批量仿真、参数扫描和结构化实验账本。
- 用已有台架曲线标定并报告不确定度，区分拟合数据与独立验证数据。

## 阶段 3：Agent 实验助手

- 通过稳定的 JSON 输入/JSON 输出 CLI 或本地工具协议接入 Agent。
- Agent 负责检索上下文、提出实验、解释差异；求解器与验收脚本保持确定性。
- 任何 LLM 提议的参数和代码变更都需要 schema 校验、测试和可追溯记录。

## 阶段 4：嵌入式对照

- 从 Python 参考模型导出可审查的向量/测试向量，供 STM32/C2000 固件仿真测试使用。
- 比较 Python 参考值与定点/浮点嵌入式实现，建立误差、时延和数值稳定性预算。
- 先离线验证，再决定是否引入 HIL；本阶段不自动连接或控制真实硬件。
