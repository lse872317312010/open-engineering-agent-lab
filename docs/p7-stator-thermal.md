# 同机型铜耗回放到二维定子热场

2026-11-06。固定规则及拓扑修订见[先行契约](p7-stator-thermal-contract.md)。
本增量从仅有体积热源，推进到Gmsh共形网格和实际scikit-fem瞬态温度求解。
电磁与机械输入沿用原公开电机和四组跨周期仿真；电阻仍为合成指定值。

## 几何与物理范围

外半径50mm、内半径27.85mm的定子截面，由原24个绕组多边形布尔分区。
绕组与铁芯共用接口自由度；外圆h=20W/(m²K)，内圆绝热，初始和环境25°C。
厚度50mm，铁芯k=25、Cv=3.5e6；等效槽绕组k=1.5、Cv=2.5e6，均为SI单位。
这些材料与边界是合成假设，没有用公开电磁材料表代替热参数证据。
无转子、端部、轴向热流、绝缘层或接触热阻，不能据此认证真实热点。

首版直接拼接显示路径的网格虽然整体连通，仍留下2340条非内圆外露面边，
故拒绝其“完美接触”结论，原轨迹和日志保留在本地拒绝目录。
修订B以OCC布尔分区恢复全接口，并增加所有非外圆外露点必须位于内圆的硬检查。
原多边形、裁剪原生面和三角形面积分别记录；区域输入功率保持不变，
按实际网格体积保守投影密度，投影比例和未投影源偏差单列。

## 实际计算和验收

三档目标尺寸4/2/1mm，保留所有细小几何特征，不能把目标尺寸当作均匀网格。
P1导热、行和集总质量、后向Euler；四组50ms实际铜耗窗后追加1s零源冷却。
冷却是热源回放，不是电机继续运行；无温度回写电阻或控制器。
每例以2.5/1.25ms运行，比较脉冲末端和冷却末端均温/峰温，保存全加热窗口及
冷却抽样全场、逐步能量账、稀疏算子、原生MSH/BREP和VTU。

独立检查包括：同网格二次制造解和线性精确极限、独立方形域二阶误差趋势、
绝热均匀热源的容量解析解、缺扇区导致外露接口拒绝及源CSV篡改拒绝。
本地Windows/Python3.14测试322通过、23项可选依赖/资产检查跳过，Ruff通过。

修订B的本地三网格为7425/9400/14566节点、13187/17045/27185单元。
制造解相对L2误差依次0.15710%/0.04765%/0.01221%；
细档线性极限最大差1.03e-14。三档铁芯面积对独立参考的相对差依次
0.23605%/0.04737%/0.01159%；裁剪绕组与原多边形最大差小于0.001预算，
实际密度投影偏差量级1e-11，仍单列保存。
四源×三网格×两时间步共24例均通过；中→细指标最大差1.471e-7K，
时间步减半最大差3.665e-9K；源积分差≤5.21e-18J，能量余额≤1.34e-16J。
四组脉冲末端最大峰值温升约16.408µK。
中途NumPy布尔/整数归档错误已修复；门槛不因这些归档错误更改。

50ms铜耗只有约5.46mJ，温升量级为十几µK。绝对温差预算通过仅表明当前短时、
低温升工况的数值一致性，不能外推长期温升或真实热参数精度。
后续已新增[同几何定子 ROM](p7-stator-rom.md)，针对固定材料和均匀槽内热源完成参数化训练及留出验证。完整 Gate C、器件/铁耗、接触灵敏度、独立电机热参照和闭环温度反馈仍待推进。

## 复现

完整CI采用Python3.12及benchmarks/p7-stator-requirements.txt；Linux需libGLU。
先按[铜耗接口](p7-winding-heat.md)生成源包，再运行：

```bash
python -m pip install -r benchmarks/p7-stator-requirements.txt
python benchmarks/p7_stator_thermal.py
python benchmarks/build_p7_stator_figure.py
```

产物在outputs/p7-stator-thermal/，summary.json分项给出通过/失败，
manifest.json保存场/算子/账本哈希。图stator-thermal.png/svg只绘制实际有限元节点场。
专用跨周期工作流已串接源映射、热求解、静态图与证据归档。
