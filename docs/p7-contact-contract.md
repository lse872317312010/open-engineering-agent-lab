# P7 有限接触热阻：实现前冻结契约

2026-10-30。部分P7-A/热接口数学验证，尚非工程P7-C、瞬态或ROM。
参数为原创理想基准，不是器件材料标定。复用Gmsh4.13.1/scikit-fem11.0.0/
SciPy1.15.3/meshio5.3.5，许可证沿用已有原文；无新增依赖。

## 方程、离散与独立参考

二维长0.1m、高0.1m、厚0.01m板，界面x=0.04m。k1=2、k2=0.2 W/(m K)，
s1=1000、s2=2000 W/m³。各区 -div(k grad T)=s。
左恒温50°C，右 q·n=h(T-25°C)，h=10 W/(m² K)，上下绝热。
界面正方向向右：qI=(Tleft-Tright)/Rc，两侧外法向通量相反。
Rc单位m² K/W，属于面比热阻而非K/W。界面自身不储能、不生热。
弱式增加厚度/Rc∫(TL-TR)(vL-vR)dy，保留独立的左右界面温度DOF。
原Gmsh共享拓扑按材料分拆成两个P1子网格；接口配对依据原节点ID与坐标，
匹配失败必须拒绝。耦合采用线性边质量矩阵length/6[[2,1],[1,2]]。
温度用相对环境值求解。已有理想接触/RT0/BDM模型不改。

独立参考p7_contact_reference.py在本契约同时提交：q'=s，T'=-q/k，
q0=[h(Tleft-Ta-B)-S]/(1+h R)，R=a/k1+Rc+b/k2，
B=s1 a²/(2k1)+Rc s1 a+s1 a b/k2+s2 b²/(2k2)，S=s1 a+s2 b。
界面TR=TL-Rc(q0+s1a)。零源独立串联电阻和Rc→0旧参考先行测试。
参考温度/功率只传评价器，不传FE装配。

## 事先固定矩阵与门槛

Rc=0.01/0.1/1 m²K/W，各n=8/16/32；另Rc=.1、左25/环境60°C的反向工况同三档。
每区n×n矩形分三角形，共4n²单元；新增n+1界面DOF。
每个工况三档温升L2相对误差阶数≥1.7，细网格≤0.5%，节点峰值误差≤0.05K。
界面热流与跳变用各自局部解析幅值归一化，细网格RMS相对误差≤1%；
保留沿界面分布，不以均值代替RMS。所有组合全局及左右子域能量余额/功率尺度≤1e-9；
自由方程残差/载荷尺度≤1e-9；Robin/左反力/界面积分相对独立解析功率尺度误差≤1e-9。
Rc=.1零源n8温度节点误差≤1e-9K；hot-ambient右功率和界面向右功率必须为负。
三档在Rc增大时零源等效传热必须严格减小（独立解析+FE各测）。
重复生成同n网格SHA256一致，原边界/材料/质量验证保留；
扰乱界面节点配对必须被拒绝。独立按三角形几何/解析区域源重算两区源功率，
不只读取载荷向量求和。导数通量可有误差，不能把界面耦合积分准确说成全场通量准确。
