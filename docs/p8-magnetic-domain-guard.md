# 磁图运行时有效域检查

`benchmarks/guarded_magnetic_map.py` 包装已有的 dq 磁图 callable。构造时提供磁图和有效域判定函数；每次输入检查数值有限、形状一致并全在域内后，才调用原磁图。任一点越界时抛出 MagneticDomainError，不裁剪、不外推；非有限或形状不符的输出也会拒绝。若上游磁图提供雅可比，包装器保留该接口并在计算导数前执行同样的输入域检查。

有效域由模型来源和数据约定决定。SciPy 训练点凸包仅反映几何范围，可能包含无效空洞，不能自动作为物理有效域。该包装器不自动构造有效域，也不改变上游的模型、控制器或积分算法。

要覆盖 motulator 自适应求解器中间阶段，必须把包装器本身接入每个实际调用磁图的植物与控制器接口，并保证没有绕过包装器的路径；本提交仅提供接口与单元检查，尚未完成这项集成。无此证据不能声称完整轨迹或积分中间状态已通过有效域检查。角度相关多参数磁图需另行适配，本接口仅接受单个 dq 参数。
