# 磁静态A场、回流电流与电感提取固定契约

先冻结方程和独立解析/能量测试，再加入FE求解与报告。
本轮为P7-A电磁基础增量，向P7-B铺路；不是PMSM、真实绕组、永久磁体或FE→FOC完成。

## 几何、物理与符号

原创有限矩形域：x∈[0,.1]m，y∈[0,.1]m，轴向深度.01m，界面x=.04m。
复用既有Gmsh双区域几何/physical标签检查；重新装配真实磁静态弱形式，不复用热场解。
左区均匀Jz=+I/(.04*.1)A/m²，右区Jz=−I/(.06*.1)A/m²，
是单匝去/回流电流对，每支截面积积分为±I；电流为DC有符号安培，不用RMS/dq。
线性各向同性无磁滞材料，mu0=4πe−7H/m；空气/空气或左mu0右5mu0。
所有材料均为合成常数，不据此声称铁磁饱和、铁耗或真实电机参数。

Az单位Wb/m，B=(∂yAz,−∂xAz)T，H=B/mu A/m；
−div((1/mu)grad Az)=Jz。左右外边界Az=0，上下自然Neumann(∂nAz=0)，
界面Az及切向Hy连续；B切向可按mu跳变，无面电流。
这是有限边界磁路，不是无限自由空间，也没有转子/运动/转矩。

弱形式K=depth∫nu gradNi·gradNj，f=depth∫Jz Ni。
场能W=depth/2∫B²/mu dS [J]；
单位电流绕组函数g=Jz/I [1/m²]，磁链lambda=depth∫g Az dS [Wb]，
L=lambda/I=2W/I² [H]。后两个FE公式共享离散场/算子，不冒充独立精度证据。
独立真值由分区二次Az与Ampere定律推导：
每区宽w，局部坐标s，符号sigma=+1/−1，
Az=mu*sigma*I*s(w−s)/(2*w*height)；
L=depth*(mu_left*.04+mu_right*.06)/(12*height)。
单匝去回流净g积分0，常量规范平移不改变磁链。

## 工况与冻结门槛

四工况：air I=2A；contrast I=2A；reverse同contrast I=−2A；
double同contrast I=4A，各n=8/16/32每区间隔，共12解。
另在最细网格实际解零电流，磁场/能量/磁链必须为0。
n32共有4096三角形、2145节点；共享界面，不人为设置内部Az=0。
独立解析解只用于求解后误差，不用于装配或界面条件。

- 每n重复生成同输入Gmsh字节hash一致；标签/拓扑/坐标/面积按旧独立几何检查。
- 相对自由残差≤1e−8；双源积分误差/|I|≤1e−12；净电流/|I|≤1e−12。
- Az全场L2阶≥1.7，B全场L2阶≥.8；n32 Az误差≤.005，B≤.05。
- 每组L解析相对误差随细化下降，阶≥1.7；n32≤.002。
- 几何单元B²/(2mu)能量与矩阵能量相对差≤1e−10；
  lambda*I=2W相对差≤1e−10，规范平移后磁链相对差≤1e−10。
- 同网格反向Az/B/lambda取负，W/L不变；双电流Az/B/lambda倍增，W四倍、L不变，
  相对误差≤1e−10。
- 最细界面两侧Hy的直接P1迹差相对I/(2h)≤.05，
  分别相对解析界面Hy误差≤.05；不能将离散连续性当作全场精度。
- 故障副本：B符号颠倒造成相对场差>1；漏深度的L相对差>1；
  错误回流符号使磁链随规范常量改变，相对正确lambda变化>.1。
  记录实际差值及固定拒绝判据，不用故障本身设定新门槛。
