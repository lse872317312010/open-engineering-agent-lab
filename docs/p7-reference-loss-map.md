# 电流参考幅值损耗与暂态有效性

2026-11-08 构建与计算，2026-11-16 复核。[先行契约](p7-reference-loss-map-contract.md)先提交为925049e6。
原R/速度表固定0.5A参考；本增量扩展恒定参考幅值I∈[0,0.5]A，并明确周期模型何时不能直接用于暂态。
机械速度仍由外部主机规定，电流指令变化不等于已验证自由机械负载ODE。

对固定R/ω、固定参考且未限幅的线性电气/离散PI，电流轨迹满足
i(I)=i(0)+(I/0.5)[i(0.5)−i(0)]。复用父版本18条冻结0.5A轨迹，新增同钟同相18条0A轨迹。
两个端点均未限幅时，中间幅值的控制电压和电流是凸组合，仍处于当前已检查域内。
对每个控制周期的精确铜耗二次型G及δx=[x(0.5)−x(0)]/0.5，累计得到：

```text
a = Σ δxᵀGδx / duration
b = 2Σ x(0)ᵀGδx / duration
c = Σ x(0)ᵀGx(0) / duration
Pmean(I) = aI² + bI + c
```

系数矩阵是能量Gram矩阵，检查其半正定性和两端点重构；R/速度之间插值系数，保持二次型非负。
c保留零参考时实际电流纹波的铜耗，零参考不等于实际电流恒为0。
0.125/0.375A、未建表温度/速度及不同初角共16条实际周期留出不参与构造系数。
新的参考调用器复用既有纯推进组件；旧固定参考调用器与父版本证据保持独立。

NumPy运行时支持R=0.3–0.42Ω、|ω|=0.5–2Ω0、同向参考幅值0–0.5A。
不支持跨零速度、反向发电参考或外推。独立二次/双线性手算、非负形式拒绝及零参考回归保留。

ReferenceSettlingGuard要求连续整数控制tick；超2A/s参考变化后等待20ms，启动也等待。
它只检查预设变化率与等待条件。下述反例表明，即使返回就绪，也不足以保证5%窗精度。
直接周期功率热窗提交还要求完整恒定参考窗口，并核对热状态时间与控制时间；
无法跳过未就绪时段再假装时间连续。非法调用不改变守卫或热状态。
连续变化参考需在控制周期内积分预测，并单独检查窗口可用性。

动态验证含两条平滑参考/转速同时变化及一条参考阶跃，均600ms，原FOC每50µs、RK4每5µs。
每2.5ms热窗始终接收实际积分铜耗，温度决定下一窗R。
平滑参考在200ms后从0.125A升至0.45A再降回；阶跃在200/400ms从0.25→0.5→0.125A。
全部预测误差保存，阶跃后20ms未就绪窗明确标记，只对就绪窗验收周期模型；
未就绪时热域继续使用实际FOC铜耗，未用猜测损耗代替。
正向平滑轨迹有原模型DOP853回放和电气半步长，热窗保持。

四条24,000s热应用同时缓变规定速度和参考幅值，新二次损耗模型与理想恒流源各自闭环；
其差异是模型间预测差，不是真实温度误差，也不代表持续执行数小时FOC。

## 本轮结果：暂态扩展未验收

446项本地测试通过、23项可选跳过，Ruff通过。18组新零参考端点均通过：
系数Gram最小特征值4.33752e-7，端点重构最大相对差4.29830e-12。
16组未参与构建的稳态留出全部通过，周期均值最大相对差0.041671%，预算0.5%。

| 动态工况 | 累计铜耗差 | 最大就绪窗差 | 预设5%窗门槛 |
|---|---:|---:|---|
| 正向50°C平滑变流/变速 | 0.023377% | 4.80344% | 通过 |
| 反向100°C平滑变流/变速 | 0.015317% | 5.21736% | 未通过 |
| 正向50°C参考阶跃，仅就绪窗 | 0.000719% | 4.58102% | 通过 |

反向平滑工况有2个就绪窗超过5%，最差窗结束于0.22s；其实际铜耗3.35852754e-5J，
周期模型预测3.53375393e-5J。整段均值误差很小，不能抵消短窗超标。
汇总明确保存passed=false，validate返回非零，工作流保留失败后的完整证据上传。
不改门槛，不删除超标窗口，不用留出反调系数或守卫参数。

阶跃后共16个评分窗标记未就绪，最大原始误差79.7329%；所有窗的实际FOC铜耗仍驱动热状态。

半步长公共控制端点电流差1.79e-12A、总铜耗相对差6.73e-10。
四条24,000s周期热应用全部满足域及热能账预算，最大模型间绕组均温差106.63µK，
最大热能余额1.27e-10J；这些模型比较不能替代失效动态窗的精度验收。
