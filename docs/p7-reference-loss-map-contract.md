# P7 电流参考幅值与暂态有效性契约

2026-11-08，执行前固定，承接#71。速度仍由外部主机规定，d参考0，q参考与速度同向。
复用原R/速度网格、PI、电磁及热模型，不扩大原功率域，不把电流指令变化等同于自由机械负载ODE。

在未限幅的线性电气/离散PI模型内，固定R/ω的电流轨迹对参考幅值I呈仿射。
每个原网格点复用经SHA核验的0.5A完整轨迹，新增同初角/时钟/重复周期的0A轨迹，
共18复用+18新增端点。利用精确二次功率积分的交叉矩构建P(I)=aI²+bI+c，
不把零参考铜耗c强制设为0，不用留出调整系数。系数矩阵[[a,b/2],[b/2,c]]最小特征值≥−1e-12，
两端点重构相对差≤1e-6。R、|ω|间双线性插值系数，I只支持[0,0.5]A，严格拒绝外推及反向发电参考。

末计均值周期铜耗相对极差≤1e-4、能量余额≤1e-8J。消除暂态≥200ms、计均值≥100ms，整重复周期。
留出T=50/100°C、速度比0.75/1.5、I=0.125/0.375A、正反转，共16例，θ0=.17，
均未参与系数构建；相对周期铜耗差≤0.5%，其余周期门槛相同。

训练/验证分进程，原18点0.5A来源和新18点0A来源逐点保留并冻结SHA。

参考有效性守卫使用连续整数控制tick：最大允许参考变化率2A/s，超过时重置20ms等待。
冷启动也等待20ms。非法/缺失/重复tick、非有限或超0.5A参考拒绝且不改守卫。
直接周期功率热窗提交还要求窗内恒定参考、完整就绪窗口和热/控制时间对齐；未就绪拒绝且不改热状态。
该守卫是当前模型范围内的有效性约束，不是任意信号的精度证明。

再200ms线性升到0.45A、200ms降回0.125A；正向50°C/反向100°C，h=20，θ0=.23。
