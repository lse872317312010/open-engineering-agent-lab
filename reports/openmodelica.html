编译链：Modelica 源码 → 固定版本 OpenModelica → FMI 2.0 ModelExchange 二进制 → FMPy。运行链：主机写四输入 → 设置时间/连续状态 → 调用生成导数 → 主机 DOP853 积分 → 读状态。旋转 dq 输入按50 μs或25/75 μs通信窗零阶保持。对照链独立运行 Python 方程/DOP853 和 C CoSimulation/RK4（≤5 μs）。ModelExchange 本身不含积分器、控制器或 PWM。

能量独立核算：储能变化 − 电气与外加板热输入 + 负载做功 + 环境散热 = 余额。Pboard 来自附加供电，不重复计算铜耗；余额不补成热源。正负载转矩在正转时吸能，反转时可能供能。
