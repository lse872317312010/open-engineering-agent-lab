# 六节点MSL热参数合成辨识契约（实现前冻结）

日期2026-10-28。基线969df28cc245e72d6fd4857da30ec726639c9430。
复用已验收OEALMSLParametric真实MSL资产，不修改MSL/电驱物理方程或既有IR。
本轮独立热激励与12参数辨识，不将热回放称为实际电驱长时运行，也不称实物标定。
六节点全部温度可观测、六热源独立可激励，是本轮合成实验假设；
稀疏传感器、未知源功、结构误差、温度相关C/R和实测有效性不在本轮范围。

未知向量theta=[C1..C6,G1..G5,Gcase]，G=1/R，节点/边顺序沿用msl-rc-contract.md。
每个观察窗使用节点积分式：
C_i*ΔT_i+Σ边G_ij*∫(T_i−T_j)dt+δcase*Gcase*∫(Tcase−Ta)dt
=∫P_i dt−δsink*∫(Gc*(Ts−Ta)+Gr*sigma*(TsK^4−TaK^4))dt。
内部边两端等量反号。输入功为已知区间平均功率，左保持生成数据时积分精确；
温度和边界使用复合Simpson积分，不数值微分带噪温度。
窗口固定：结温0.5s，其余五节点20s，非重叠；采样0.05s，窗口均为偶数区间。
按公开默认C归一化节点残差，再按列范数缩放；
SciPy.optimize.lsq_linear有界求解，12维全部辨识，不用真实参数作初值或正则。
C范围.05..1000，G范围.05..20，恢复R=1/G。
归一化设计矩阵秩必须12、条件数<=1e5；零/不足激励必须拒绝。

生成器私有合成真值C=[75,90,260,.8,32,130] J/K，
R=[.75,.5,2.4,1.05,1.5] K/W、Rcase=2.8；
已知Gr=.02m²、Gc=1/3 W/K。噪声各节点IID高斯sigma=.02K。
