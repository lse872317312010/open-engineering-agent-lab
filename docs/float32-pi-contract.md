# float32 PI 部署准备与误差预算

2026-10-23。本轮保留 double PI 参考，新增独立 binary32 API oeal_pi_step_f32。
方程、积分/限幅/回算次序、零 Ki 和错误返回语义不变。
参数、状态、输入、输出数组必须不重叠；成功后由调用方显式提交下一状态。

## 实现与编译

所有数值字面量使用 f 后缀，调用 fabsf/fmaxf/hypotf/expm1f。
静态断言要求 32 位、24 位有效尾数、二进制基数的 float。
禁止 fast-math，关闭浮点乘加收缩，使用 -Wdouble-promotion 和 -Wconversion。
目标侧检查未定义符号：不得出现 __aeabi_d* 或 double 版 libm 符号。
这只检查该对象直接依赖，不证明后续链接的 libm 内部绝无 double。

## 预声明验证域与容差

共享手算向量不改动；使用现有 8 组向量和 2000 步确定性输入序列。
输入参数先量化为 binary32，再交给 Python double 参考，以区分外部输入量化和
控制器内部逐步舍入。每个输出/积分状态逐样本比对，绝对容差 2e-4（电流 A/电压 V），
相对容差 2e-5；布尔标志必须一致。报告最坏索引、全部误差和独立浮点参考版本。
该预算约为 24 V 量级的十余个到百余个 float ULP，覆盖有状态累积，
不适用于任意增益、任意时长、极小/极大参数或安全阈值决策。

另检查正反转正弦输入、持续饱和和恢复，输出幅值上限允许 2e-5 V 舍入裕量；
NaN/Inf 在每个参数/输入/状态位置都要拒绝，输出清零且旧状态逐字节不变。
零/负周期、非正限幅、负增益、零 Ki 非零状态和有限值溢出也必须拒绝。
目标 FPU 舍入模式、FTZ/DAZ、libm 实现仍须在板端 PIL 记录与重验。
