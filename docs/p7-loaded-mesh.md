# 公开电机带载三档网格敏感性

[先行冻结契约](p7-loaded-mesh-contract.md) / [交互报告](https://github.com/lse872317312010/open-engineering-agent-lab/actions/runs/41995793750/artifacts/13400123591) / [新增原生求解](https://github.com/lse872317312010/open-engineering-agent-lab/actions/runs/41995376711)。

固定原SPMSM_001机型、材料、50mm叠长、坐标和峰值电流，四个相对机械角0、11.25、22.5、33.75°，每角比较零电流、(0,2)、(1,1)、(−1,1)A。Kgeo/Kmesh为1、1.5、2三档，合计48个场工况；其中32个粗/中网格解为本轮新求解，16个细网格解在逐文件/来源核验后从此前结果复用。每个网格的转矩增量均使用该网格、同角的真实零流基准。

事前固定的中→细差值预算为磁链向量差/0.05Wb≤0.03、绝对转矩差≤0.05Nm，且节点数逐档递增。粗→中与中→细差值和是否递减分别保留，不以非单调差异推断收敛阶；增量转矩相邻档差另行记录，不混同绝对转矩差。

**16组角度/电流组合均满足固定预算**，全部节点数逐档增加。中→细最大磁链向量差/0.05Wb为0.00134410026，即约67.205μWb；最大绝对转矩差0.00249725745Nm；同网格零流扣除后的最大增量转矩差0.00160424848Nm。逐组合数据、非单调标记及粗→中差值见报告JSON；这些是有限离散算例的网格敏感性，不是对真实误差的上界。
