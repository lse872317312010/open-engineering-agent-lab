## 发现并修正桥方向锁存的负耗散

未适配的上游平均压降方向在set_gate_signals时锁存，
小电流换向/近零初值后可过期。
[诊断失败运行41372853152](https://github.com/lse872317312010/open-engineering-agent-lab/actions/runs/41372853152)
在tick1记录桥J=−1.03759e−8、最小RHS桥功率约−8.28885e−4W，
并非舍入误差。
[原失败CSV/gzip/JSON证据](https://github.com/lse872317312010/open-engineering-agent-lab/actions/runs/41372853152/artifacts/13109409325)
保留，不标为通过；更早41372639179是同一检查的首次触发。

先增加实际上游桥的“过期方向负耗散/刷新后非负”反例，
再采用上游已支持的
sign(i)=2/pi atan(i/.02A)平滑配置，并在每次上游输出评估时，
以原样缓存的门极/blanking信号重新调用上游set_gate_signals刷新方向，再评估输出。
门极事件/控制时钟不变，不复制或改写压降、电机或积分器方程。
只适用本Gc=0线性机：当次电流由状态确定，与当次端电压无代数依赖。
.02A是合成仿真的平滑宽度，不是器件实测参数。

原锁存方案未通过；通过的是上述明确适配后的平均桥。
全部电流/几何/求解器/验收阈值保持，未对桥耗做abs或max(0,...)。
最终四组最低热功率均为0，独立功率重算最大差6.94e−18W。
报告的contract.md包含这一修订，不将适配混同于原模型默认行为。

## 整数时钟与能量窗口接口

新增[整数时钟](../src/oeal/multirate.py)ThermalWindowClock：
控制50000ns，热2500000ns，ratio50。
每个已接受控制时刻k按以下顺序：
1. 读取真实积分器累计铜/桥J；
2. 若k>0且k%50=0，关闭旧窗口[k−50,k)，取ΔE；
3. 平均功率ΔE/.0025传给热ROM，推进一次；
4. 更新并保持Ractual=.3[1+.00393(Tleft_mean−25)]；
5. 采样当前状态并计算下一控制周期的FOC命令。

非边界保持温度，年龄为距上次热更新的控制tick数；
名义控制R始终.3，右区温度不调节桥压降。
冻结R对照仅冻结物理定子R，热模型仍推进。

旧AffineThermalROM.step接收端点并做梯形平均；
窗口均值不能再次当作端点。
新增[step_average](../src/oeal/thermal_rom.py)直接用区间平均输入，
CN右端是dt*Fr*mean。每对象锁定端点/均值模式，
混用、非法输入、重复/漏序tick或负/超范围能量在更新前拒绝。
线性功率斜坡的独立解析积分检查了窗口平均，不仅检查常功率。

每组恰5000个控制命令、5001个含终点样本。
400Hz组恰100个热更新，800Hz细化组200个，
年龄分别在0–49和0–24tick。
上游Simulation的stop放在最后控制调用和终点之间，
到.25s后显式完成终端窗口关闭，不额外调用电流控制器，
避免为取得终点样本而多发一条命令/多跑一个区间。
实际终点时间偏差检查≤5e−12s；整数时钟不通过累加浮点周期调度。

此时铜/桥耗仍非负，能量来自外部机械驱动并部分返回DC端。

## 能量、端口和故障检查

每组70000个RHS试探功率记录，试探时间可重复/非单调。
四组窗口累计铜/桥输入与真实积分差均记录为0，
窗口中各微步能量差之和误差最大1.36e−20J。
最大源倍率0.71118，在原[0,2]域内，无裁剪。

电端按每控制节点重算
DC源J−铜J−桥J−负载功J−摩擦J−磁场/动能变化，
最大余额约9.98e−15J；
热端使用源积分、左恒温含Mdu/dt的反力、右对流、接触流与两区储能，
全局/区域最大余额约8.99e−17J。
这些首先证明离散能量账一致，不单独证明物理准确。

故障副本相对实际积分的误差：
- 用末端损耗乘窗口长：约1.01e−5至4.32e−5J；
- 丢最后热窗口：约3.24e−5至6.49e−5J。
两类均超过原1e−9J拒绝条件；源映射正确结果独立保留。
重复、漏序和非整数tick，输入均值/端点混用及非法输入状态不变均通过单元回归。
