# P7 电驱铜耗窗口到同机型定子 ROM 的直接回放契约

2026-11-06。执行前固定；承接原跨周期电驱、24槽热源映射、定子 FE 和参数化 ROM，不修改已有方程、训练集或验收门槛。

四条 50 ms 跨周期轨迹（forward/reverse × 5/2.5 µs）各有 20 个连续 2.5 ms 铜耗源能窗口。每窗口平均功率 P=ΔE/Δt，以同窗口、同源形状驱动既有 ROM 与同网格全阶热模型。ROM 基和推理包先训练冻结，输入和产物 SHA 均核验；h 为 12、20、40 W/(m²K)，冷初态和环境均25°C。有限元和 ROM 均用 2.5 ms 后向 Euler；窗口期间功率视作均值。

固定验收：每组20窗口、21端点；源窗口连续、非负、有限、完整，逐窗口功率不超过冻结功率上界且总源能与原CSV一致。每个端点同离散全场最大节点差≤1e-5 K、两个均温最大差≤1e-5 K，两模型源能−散热−储热最大余额≤1e-8 J。记录源能、峰值温升和实际相对误差；短脉冲温升很小，不把绝对误差门槛解释为全工况相对精度。原始结果完整保存，失败返回非零。源文件篡改、窗口缺失/倒序、越界功率应被拒绝；已有独立两节点解析回归保留。

这是预先计算的50 ms电驱轨迹向热模型的单向回放，非电驱与热模型实时双向联动、非1200 s持续电驱、非硬实时或真实温度测量。材料、边界、绕组热源空间分布与参数化范围沿用原契约。
