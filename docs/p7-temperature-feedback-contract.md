# P7 温度—电阻—铜耗双向接口契约

2026-11-08，执行前固定。依赖#67的冻结短时ROM；不重拟合电磁或热模型。
新增合成电阻定律R(Tw)=0.3×[1+0.004×(Tw−25)]Ω，Tw有效域0–125°C，
系数是接口试验参数，不是该电机的材料辨识结果。材料k/Cv不随温度变。

采用原20kHz PI、48V平均SVPWM、公开静磁衍生角度模型、机械ODE、
±40rad/s初速、0.1rad初角、±0.5A参考和±0.05Nm负载。
PI增益以25°C参考电阻固定；5µs RK4每10步控制、每500步（2.5ms）更新热状态。
电驱每个RK阶段使用当前窗口冻结电阻计算方程和铜耗，累计积分电能。
第n窗末用该窗铜耗积分/窗宽更新热模型；新绕组均温和电阻只用于第n+1窗。
所有时钟以整数tick表示，跳窗、重复/倒序tick、非法能量/温度/功率拒绝，
错误调用不得改变热状态或已接收窗口。禁止以裁剪继续运行。

线性热算子以环境为温升零点。初始与环境同温，环境为25/75°C；
75°C采用原冻结包温升平移50K，储热与散热仍相对于该环境计量，
不引入相对冷环境的初始热能或擅自改变导热/对流系数。

固定四例：正向h=12、反向h=40，各在25/75°C环境下连续50ms闭环运行。
每例独立运行ROM闭环与同网格全阶热闭环，两者分别生成自己的控制指令、
损耗积分、温度和电阻。全阶BE与ROM同窗宽；记录全部21热端点与1001控制端点。
对照全场相对差=max|ROM温升−FE温升|/max|FE温升|≤5%，
全场绝对差≤1e-5K，两均温差≤1e-5K；电流差≤1e-6A、角差≤1e-7rad、
转速差≤1e-5rad/s。该对照包含电阻反馈造成的两条轨迹输入差异。

每条热源积分须与电驱铜耗差≤1e-12J；热源−散热−储热≤1e-8J。
联合余额=输入电能−摩擦功−负载功−磁/动能变化−热储能−散热≤1e-5J，
铜耗是内部传递，不能再次扣除。每条R末−R初>1e-10Ω，记录实际微小反馈幅度。
所有电气阶段仍受|id|+|iq|≤2A、既定电压限幅约束。

独立检查：75°C正向ROM的逐控制周期命令与窗口电阻用DOP853回放，
电流/角/速差≤1e-4A/1e-5rad/1e-3rad/s。
同工况以2.5µs电气步长、1.25ms热窗细化；公共端点电流/角/速差同上，
全场温升差≤1e-6K、均温差≤1e-7K。使用独立两节点手算验证热能和温度平移，
测试未来/重复tick、能量减少、非有限/越界功率、温度越界及拒绝不改状态。

源码、契约、冻结包、源模型SHA均记录；原始控制CSV、热场NPZ、误差、
能量账、PNG/SVG及manifest独立保存到outputs/p7-temperature-feedback/。
失败返回非零，预算不因结果调整。仅为50ms分区显式双向仿真原型，
微小自热不能解释为已验证长时温升稳定性、热保护控制或真实温度精度。
