# 带载角步再次减半：先行契约

2026-11-05。前一批真实中点显示11.25°粗角对绝对转矩插值超过原0.10Nm预算，失败不得消除。为量化进一步细化，冻结新比较：

同一机型/材料/2D 50mm叠长/固定dq零位和Kgeo=Kmesh=2。将0–45°细分成2.8125°机械角，新增2.8125、8.4375、14.0625、19.6875、25.3125、30.9375、36.5625、42.1875°八个中间角，每角零流及(id,iq)=(0,2)A，共16个新增原生FEMM解。已有0、5.625、…、45°九角×两电流共18点仅经生产源码、manifest及原生文件复核后复用，实际闭合点不可周期复制。总17角×两电流共34点。

分别以相邻5.625°真实场的磁链和绝对转矩线性插值与新增2.8125°中点比较；逐点磁链向量差/0.05Wb≤0.02、绝对转矩差≤0.10Nm，同角零流扣除后的转矩增量误差另报。与此前11.25→5.625°阶段分别汇总最大差，电流工况集合必须一致，标注角点不同；即使差值缩小也不声称连续误差界或收敛阶，出现失败保留原值。
