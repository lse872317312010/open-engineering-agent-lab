运行机制与端口

① 电气 · 旋转 dq
输入 vd / vq [V] → id / iq [A]
温度反馈 R(Tw)；电流产生 Te
输出转子速度供反电势反馈
② 双惯量 · 弹性传动
Te → 电机惯量 → N=10 → K/D → 负载
负载转矩 Tload [N·m] 交换轴功
电机/负载粘性与轴阻尼产生热
③ 三节点热网络
铜耗 → 绕组 ↔ 壳体 ↔ 板级
机械耗散 → 壳体；Pboard → 板级
壳体/板级 → 25°C 环境

外部主机：读状态 → 写入电压/负载/板热 → doStep(t,h) → 读取下一状态。输入在旋转 dq 坐标零阶保持；示例通信周期 50 μs，变步长案例交替 25/75 μs；内部 RK4 ≤5 μs。外部控制器与 PWM 不在此 FMU 内。

能量独立核算：储能变化 − 电气与外加板热输入 + 负载做功 + 环境散热 = 余额。Pboard 来自附加供电，不重复计算铜耗；余额不补成热源。正负载转矩在正转时吸能，反转时可能供能。
