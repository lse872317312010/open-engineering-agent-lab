# 实际电驱与非线性MSL散热联合契约（实现前冻结）

日期2026-10-27；基线c4499fb66cfed99d289de9f7f36f895b319c5c62。
在原电驱连续热提供方协议上增加可信对象的三条散热积分与合成热初态。
七IR、默认25°C原生路径和旧8状态MSL提供方兼容；无JSON任意FMU路径。
新10状态FMU和原始MSL/编译器均沿用PR24已固定版本及源散列，不修改物理模型。

同一motulator连续求解器积分电磁/机械、六温度、原能量账和三条支路积分。
每个RHS投影实际六温度、实际输入热累计及实际三支路积分到FMU；
三支路之和必须等于主机ambient_j，导数之和必须等于实际环境热流。
FMU返回的六热导数、输入热导数和三条散热导数直接进入主机求解器；
不得另跑热积分、由余额反推功率或将RHS试探当接受轨迹。
XML解析状态顺序及编译别名；接受点先completedIntegratorStep再核对全部公开输出。
保留试探/回退非单调时钟，控制点严格递增。

电驱源/DC/AC/损耗路由与温度反馈沿用msl-drive-contract.md，
控制器名义R/L/磁链冻结。所有六节点合成初态80°C，环境25°C；
电机初始电流与转速仍0。这是为短时激励散热支路的合成热初态，不是加热过程或实测。
初始储热按ΣC*(80−25)记录；全部储能/热余额使用相对初态的储能变化，
不可把初始储热误记成输入或能量不守恒。
Gc为等效W/K，Gr为合成有效m²。无流场、材料标定、器件额定值或真机结论。

固定案例与全部参数见预先提交的msl_cooling_drive_reference.py：
Ts50us、48V、5A、载1.5N*m，.005s阶跃，平均桥无延迟，
RK45 rtol1e-8/atol1e-10/maxstep20us，持续.1s；
辐射反馈/Gr0线性极限/冻结R/连续变化Gc/10us细步五组；
真实PWM组.02s、5us步、死区1us、压降.4V、两采样延迟；
回馈组.04s、−2A、−2N*m、10us步。
Gr默认.02，Gc默认1/3；变化组Gc=1/3+.25*sin(2*pi*t/.1)，连续非事件输入。
不搜索控制参数，不宣称长时耐久或保护事件。

每组与独立Python端口方程提供方按相同实际电驱/积分器/初态配对，
核对全控制点六温度<=2e-7K，dq电流/速度/电压<=2e-5各自SI单位，
三支路积分及ambient_j<=1e-7J。
这验证独立热端口实现，不是独立电机模型；原生电机数值验证沿用既有证据。
所有序列化RHS逐行独立重算：六热导数<=2e-7K/s、各环境支路<=2e-7W，
输入功<=1e-8W，ΣC*Tdot+Qambient−ΣPheat<=1e-8W。
接受点状态投影温差<=1e-10K、所有积分<=1e-8J；
主机三支路和ambient_j差<=1e-8J，导数和差<=1e-8W。
本地余额<=2e-5J+2e-4*绝对源功积分，热余额<=1e-7J。
全细流电流峰值<=6.5A，末10%平均iq跟踪误差<=.1A；
从铜耗/真实电流恢复R误差<=1e-10ohm；冻结R误差<=1e-12ohm。
细步与正常全共同控制点沿用温度/电流/速度/电压门槛。
回馈真实source_w<−.1W；辐射各组初始radiation_w>1W，Gr0辐射严格0。
Gc变化组核对真实输入时序及支路响应，不以温升改善作为短时门槛。
反馈/冻结铜耗积分差绝对值>=1e-5J。
