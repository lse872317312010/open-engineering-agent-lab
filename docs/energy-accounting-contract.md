# 电驱—热能量一致模式与机器人端口审计：实现前契约

遵循用户仿真验收约束，真机由用户负责。本轮延续 P6 与统一 IR，

## 范围与兼容性

新增 opt-in `energy_consistent=true`，旧实验默认关闭，保留旧轨迹和优化目标。
首版支持 motulator 线性 PMSM、单惯量机械、恒压或电容母线，以及无夹具的 UR5e
单关节接口审计。不支持该模式下的非线性磁图、铁损支路、二极管整流母线或独立
双惯量模型；必须显式拒绝，不能默默跳过。模型仍调用固定上游 motulator 方程，
不复制或重写电磁/逆变器求解器。

## 符号、端口与方程

功率单位 W，能量 J，温度 °C，热容 J/K；电流为空间矢量峰值。
正输入功率流入本地电驱与六节点热系统，正负载功流向外部机械负载。

- 实际交流端口：Pac = 1.5 Re(u_ab conj(i_ab))。
- 上游理想桥直流功率：Pbridge = Vdc * idc_bridge；实际阈值压降已在该支路体现。
  Pcond = Pbridge - Pac，保留有符号端口差，不以绝对值或剪裁强制守恒。
- 额外器件研究损耗：Paux = 1.5 * 0.02 * |i|² +
  6 * 20e-6 / Ts * |i| * enabled。它是等效直流并联耗能支路，不是晶体管寄生模型。
  新增实际直流电流 Paux/Vdc；电容母线的 RHS 必须真实扣除这部分电流。
  器件热 = Pcond + Paux；不能再把阈值压降估计重复计热。
- 铜损 Pcu = 1.5 R(Tw)|i|²，转子粘性摩擦 Pf = B*w²；
  分别进入绕组和机壳热端口。六节点温度在同一连续求解器中积分，
  C*dT/dt = Pheat - G*(T-Ta)。温度反馈 R(Tw)=R25*(1+0.00393*(Tw-25))。
- 线性磁储能 Wmag = 0.75*(Ld*id² + Lq*iq²)，电流由磁链状态独立恢复；
  Wrotor = 0.5*J*w²，Wbus=0.5*Cdc*Vdc²，Wthermal=Σ Ck*(Tk-Ta)。
- 恒压母线源端口为 Vdc*(idc_bridge+Paux/Vdc)。
  电容母线源端口为 Vbus*Iexternal；边界在电容馈入端，
  外部电源/馈电电阻不在本地热边界内。
- 使用同一求解器增加功率积分状态，直接积分实际端口，不从守恒式反算源功率。
  保留有符号负载功 Eload=∫ tau_external*w dt 与绝对源功积分用于尺度判定。
- 本地余额：
  Rlocal = Esource + Qshaft_import - Eload - ΔWmag - ΔWrotor - ΔWbus
  - ΔWthermal - Eambient。内部损耗已进入热储能，不能再当外部损耗重复扣除。

## 机器人边界与误差

UR5e 与电机仍采用显式 Jacobi 宏步，不能宣称隐式全系统守恒。
记录实际 MuJoCo 机械能、恒定外加轴转矩做功、其他位置执行器做功、
被动力做功、传动弹性能与非负阻尼热；阻尼热以宏步保持功率进入机壳，
并在本地边界明确记为来自传动的热输入。

分别报告电机端口功、机器人轴端口功、弹性储能、阻尼热之间的接口余额，
以及机器人积分/做功求积余额。它们不强制置零，不把执行器做功或联合仿真
误差冒充损耗；有接触夹具的全局平衡本轮不声明覆盖。

## 固定验收与独立检查

1. 旧测试、IR 0.1、五配置接口、ARM/SIL 与既有物理目标保持有效；新模式默认关闭。
2. 先增加磁能/端口/热网络的手算或解析极限测试，再接入实际连续模型。
3. 六节点恒功率热积分与独立增广矩阵指数对照；总储能+对环境散热与输入热误差 <1e-8 J。
4. 对恒压平均、PWM、带阈值/死区、电容母线与机器人电机局部边界：
   全段 max|Rlocal| <= 2e-5 J + 2e-4 * max(Esource_abs)。
   热网络分账误差同样独立报告；不得靠改源端口、抹掉符号或放宽阈值过门槛。
5. 增加解析负载/摩擦极限、回馈或可逆功率工况；检验额外直流支路使电容
   出现可量化的能量/电压变化。导出原始流和输入/源码/依赖散列。
6. 机器人以 200 / 100 / 50 μs 宏步报告接口余额与能量变化；
   接口误差作为诊断，不用局部余额的绿色 Gate 代表整个机器人系统已闭合。
7. HTML/PDF 增加能量去向、储能/散热与余额曲线、工况切换、时间状态和 CSV。
   真实浏览器检查离线、首末点、导出、390 px 布局和失败状态展示。
