# 一小时热网络回放验收

本轮对应路线图“长时、多工况与鲁棒性”的首个有限交付。
证据等级为 `model_simulated`；不是一小时电机/机器人联合仿真。

## 固定输入与判据

- 六节点 RC 模型使用既有合成参数，不重新拟合参数或搜索控制器。
- 环境温度分别为 -10 / 25 / 60 °C，各自保持恒定，从环境温度初始化。
- 每个场景持续 3600 s，分别以 1 s 和 0.5 s 保持功率推进。
- 按 winding/core/case/junction/board/sink 顺序输入 W：
  前 600 s 为 [40,5,0,15,0,0]；随后 1200 s 为 [10,2,0,3,0,0]；
  随后 600 s 为 [60,8,0,20,0,0]；最后 1200 s 全部为零。
- 独立参考直接按热流端口重写 ODE，使用 DOP853，rtol/atol 为 1e-11。
  不调用生产模型的 conductance、rates 或 advance 计算参考解。
- 四个功率分段末端温度最大差 <= 2e-7 K；所有采样有限且不低于环境。
- 输入功积分减去对环境散热与最终储热，采样 Simpson 求积余额 <= 0.5 J。
  Simpson 在每个功率段分别使用，不跨不连续输入积分；源能量按保持功率精确计算。
- 参考 ODE 另积分对环境散热，独立参考能量余额 <= 1e-5 J。
- 账本副本漏记 10 J 必须超过固定余额门槛；不修改物理仿真轨迹。

## 复现与产物

运行 `python benchmarks/validate_thermal_endurance.py`。
`outputs/thermal-endurance/` 包含六组原始 CSV、哈希、环境、输入序列、阈值与结果 JSON。
专用 Actions 工作流保存完整证据与 pip freeze。源码提交由 CI 注入 GITHUB_SHA。

## 结果与边界

本地 Python 3.12.14 / NumPy 2.3.5 / SciPy 1.17.0 首轮六组通过；
分段末端最大温差约 9.30e-10 K，采样能量余额绝对值最大约 4.38e-9 J。
远程结果以本 PR 的 Thermal endurance evidence 运行及 artifact 为准。

这些固定线性 RC 回放检查的是长时间数值一致性与账本，没有覆盖参数辨识误差、
温变热阻/热容、非线性温度反馈、真实热源功率误差或物理温度额定值。
三个环境的温差响应在本线性模型中具有平移不变性，不是三种真实环境下的准确性证明。
后续继续补机器人长轨迹、参数偏差和载荷留出；本轮不将路线图第三项整体标记完成。
