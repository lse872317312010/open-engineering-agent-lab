# P7 多速率电驱→热ROM：实现前冻结契约

2026-11-02。固定motulator commit 2ffbf1ae52d5fadcdffd85d10c80dd15fd2e39fa、
既有OEAL电流PI/FOC与22维接触ROM，离线仿真，部分P7-C/D。
不是实物热几何、PWM开关/完整固件、实时调度或传感器温度估计。

## 两个时钟与功率传递

控制周期50000ns（20kHz），热周期2500000ns（400Hz），整数ratio=50。
每个已接受控制时刻k先读取上游求解器累计铜耗/桥耗，
若k>0且k%50=0，关闭[k−50,k)窗口，取真实累计差ΔE，
平均功率Pbar=ΔE/.0025，将热模型推进一次，再让下一个FOC控制周期读取更新温度。
非边界保持上次温度，禁止未来值/重复/漏序/小数tick。
末端k=N只关闭最后窗口和导出终点，不再发出新的控制命令。
仿真stop位于最后控制调用和终点之间，再显式完成终点采样，避免多跑一个控制区间。

原AffineThermalROM.step接收端点倍率并做梯形平均，不可把窗口均值再当端点平均。
新增step_average直接接收区间平均倍率，CN右端dt*Fr*mean，
每对象锁定端点/均值模式，混用或非法输入在修改状态前拒绝。
新增NumPy-only ThermalWindowClock：两个整数周期、逐tick单调累计J、正的源尺度W；
边界时调用sink.step_average，源超界/负能量/重复/漏tick不得推进状态。

## 实际电驱和热源身份

复用motulator真实PMSM/机械/平均桥模型与现有DriveController，
不复制其求解器/电机/控制方程。平均逆变器、48V、无PWM、无计算延迟、桥阈值压降.1V，
名义R=.3Ω、Ld=Lq=.0008H、psi=.03Wb、7极对、J=.002kg m²、B=1e−5Nms。
完美传感器；控制器名义参数冻结。
采用小电流以保持既有等效板源域，不缩放/截断真实损耗：
铜耗1.5*R(T)*|i_s|²，桥耗为真实DC桥端功率减AC端功率；
辅助Subsystem在上游RHS积分铜/桥/源/AC/摩擦/负载J，不用采样末值替代积分。
不含额外开关损耗、铁耗或旧六节点热源，旧控制器热对象替换为只读板温显示视图。
温度更新Ractual=.3*(1+.00393*(Tleft_mean−25))，整个控制周期保持；
记录平均/保持温度与R的使用时刻，控制器名义R始终.3。

铜总W均匀映射材料区一，桥总W映射材料区二，倍率=实际W/[.04,.12]；
传递J一比一，不重复计热。板参数/容量/边界均沿用已验收合成几何，不能称为实物绕组/桥结温。
外部机械负载功和摩擦另记，不重复送入两个板源。

## 实现前工况和门槛

- feedback：Rc=.07，热400Hz，负载+.02Nm；

- fine-thermal：feedback但热800Hz、ratio25，控制仍20k；
