## 2. 对象与独立几何/绕组参考

公开12槽/8极/p=4/三相、Ntcoil34、双层、Npcp1、coil_pitch1，保留上游绕组位移。
定子Rint=.02785m/Rext=.05m，转子铁Rext=.02385m/Rint=.011925m，
径向全极距磁体厚.003m，间隙.001m，两铁芯轴长.05m。
SlotW22的H0=0、H2=.01895m、W0=W2=.31415927rad；
每槽面积=angle/2*((Rin+H0+H2)^2−(Rin+H0)^2)。
每磁体面积=pi/8*((Rrot+.003)^2−Rrot^2)；
铁芯及总槽/磁体面积分别按圆环减法/数量求和。

独立解析面积与PYLEECAN几何方法相对差≤1e−10；
实际离散轮廓shoelace面积相对差≤.001。
SWAT-EM实际绕组矩阵应有24个非零线圈边，绝对匝数34，
每相有符号匝数和0，绝对匝数和272；不自编绕组替代生成器。
负例：mm当m/漏掉线圈两边因子必须能识别。

上游M400-50A含44个[H(A/m),B(T)]节点，磁体Br1.2T/mur1.05、径向交替磁化。

## 3. 实际FEMM运行与单位

使用PYLEECAN MagFEMM原生有槽几何、非线性BH和滑移带；
全机sym=1，is_periodicity_a/t=False、is_get_meshsolution=False、
is_set_previous=False，保留求解器默认1e−8精度。
上游FEMM默认Lfemm=1m、输出先按单位轴长计算，再沿z轴积分。
每次记录原生depth和库输出；独立按Lmodel/Lnative=.05转换
原生三相磁链与加权/MST转矩，对照PYLEECAN物理输出，禁止再乘一次叠长。
φ差/.05Wb≤1e−8、T差/1Nm≤1e−8。
时间轴仅t=0；OP的60rpm仅供上游非零时间归一化，电磁场实际freq=0，
不是动态转速、反电势或时步仿真。

三档Kgeo/Kmesh=1/1.5/2，实际节点/单元数必须递增。
各档θm=0分别施加abc=(0,0,0)、(0,+sqrt(3)*2.5,−sqrt(3)*2.5)A及反向；
这些是明确相电流，不在dq零位未校准前称作iq。
最细另求θm=45°/90°空载，以及轴长改为.1m的θ0空载（唯一明确派生输入）：
合计12个静磁算例。每例保存原生fem/ans、原始库输出/字典、实际电流、三相磁链、
两种转矩、96个滑移带B采样、几何/绕组和环境版本。
Native铜/磁体/铁芯分组面积与独立解析值相对差≤.005。

## 4. 固定物理验收

- 实际相电流与输入差≤1e−10A；基本输出全部有限，空载磁链范数>1e−6Wb。
- 中→细相同激励的磁链矢量差/.05Wb≤.03，物理转矩差/1Nm≤.05。
- 各例加权应力转矩与原生滑移带MST差/1Nm≤.05；
  两者共享FE解，不当作第三方求解器验证。
- 8个全极距交替磁体：空载θ45°磁链约为θ0负值，θ90°约为原值，
  磁链矢量差/.05Wb≤.02；这只验证指定对称位置，不是完整角步收敛。
- .1m/.05m叠长空载磁链、转矩应倍增，差分别/.05Wb和1Nm≤1e−6，
  采样B矢量相对差≤1e−6；原生1m场保持。
- 不强制有槽机器T(+I)为T(−I)的负值：保留真实齿槽/磁阻偶分量。
- 未通过则保留失败，不修改门槛或悄悄简化槽/磁体/材料。
