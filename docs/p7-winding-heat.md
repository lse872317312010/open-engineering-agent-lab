# 公开电机的铜耗到绕组体积源

2026-11-06。[冻结契约](p7-winding-heat-contract.md)规定范围。
本接口承接[跨周期电机轨迹](p7-period-crossing.md)，作为工程损耗到热场的第一步。

从固定公开PYLEECAN几何读取24个槽内绕组区域，用独立鞋带公式计算面积；
按50mm有效叠长换算总体积1.3332443e-4 m³。
多边形总面积与原独立绕组面积相对差9.7334e-7，满足0.001门槛。
四组轨迹的实际铜耗积分按50个控制间隔形成2.5ms热窗，
每窗平均功率按体积分配；不使用末端功率或电源输入代替损耗。

本地80个热窗、1920条区域源记录通过；单窗能量最大差1.09e-19 J。
分区功率密度W/m³乘体积还原W，再乘时间还原原始J。
这项守恒是映射正确性的检查，不是局部温度或真实发热分布精度。
19项独立数学/故障检查覆盖矩形面积、不同体积分配、积分窗口、
非零账本初值、漏点、错误时钟、部分窗、负/非有限能量及重复标签。

Windows/Python3.14本地完整测试316通过、25项可选检查跳过，Ruff通过。
原跨周期远程证据见其方法页；本轮空间源接口使用新提交工作流另行验收。

## 复现

先按跨周期说明生成四份CSV，再运行：

```bash
python benchmarks/p7_winding_heat.py
```

输出outputs/p7-winding-heat/中的regions.csv、windows.csv和summary.json，
记录几何、四份输入轨迹及生产脚本SHA。专用跨周期工作流已增加该步骤并归档。

**物理假设：** 使用合成指定相电阻0.3Ω；暂将全部铜耗等效均匀沉积在
槽内整个绕组区域。区域不是裸铜，未指定铜填充率；端部电阻尚未分离，
没有预测相别、导体位置、交流集肤或局部热点。铁耗、磁体损耗和器件损耗未引入。
不生成温度，不声明热导率、接触、边界、网格收敛或整体Gate C已经完成。
下一步需在同几何下明确热材料/边界与端部假设，完成热网格和独立参考再接ROM。
