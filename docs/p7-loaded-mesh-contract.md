# P7 带载网格敏感性验证：先行契约

日期：2026-11-05。研究网格改变是否会显著影响先前公开电机带载磁链及转矩。固定SPMSM_001原几何、材料、50mm叠长、PYLEECAN/FEMM版本、峰值dq与零位；数学与单位沿用[p7-current-holdout](p7-current-holdout.md)。不拟合模型或改原数据。

四个相对机械角0、11.25、22.5、33.75°各取(id,iq)=(0,0)、(0,2)、(1,1)、(−1,1) A：零电流、正q单轴、两个混合点。三档Kgeo/Kmesh=1、1.5、2，共48个场工况。经核验复用已有2档16点；新增1和1.5档各16点共32个实际静磁解，保留原生文件及来源。不得称复用为新解。

提前固定：每个角和电流比较相邻两档实际dq磁链向量差/0.05Wb，以及绝对转矩之差，分别记录粗→中和中→细。中→细须分别≤0.03及≤0.05Nm；各档转矩与气隙转矩差≤0.05Nm、原单点几何/单位/角度/回读检查沿用。节点数量必须各档递增；差值未递减单列，不能假设单调收敛或推断收敛阶。转矩增量同样按各网格同角零流基准计算并另列，不能用绝对转矩差代替增量差。

原生证据完整性与网格敏感性结论分开：损坏/缺失/来源不符使证据失败；网格预算未通过必须保留失败数值并可生成报告，不改门槛。核验求解器、源码、机型、零位及各原生文件hash，测试错来源/篡改/漏工况拒绝。

交互报告需呈现三档网格、实际几何与组件状态、磁链/绝对及增量转矩、各点相邻档差和失败状态，可下载完整数据及图表，验证浏览器和移动布局。结果仅是有限角度和电流的网格敏感性，不等同连续角域、真实物理精度、动态运动场或完整Gate B；真机由用户负责。
