# 统一实验与可验证设计迭代：实现前契约

2026-10-23。仿真验收，真机由用户负责。保留 IR 0.1 和已有物理验收，
本轮新增 IR 0.2 的固定模型注册、统一运行/结果/验收接口及优化实验。

## 模型与接口

- 固定注册 native FOC、native 九状态关节、motulator 电驱、Baldor 磁图电驱、
  motulator + Menagerie UR5e 单关节；不接受 import、shell、表达式或模型文件路径。
- ModelSpec / ExperimentSpec / SimulationResult 使用 0.2；数值配置明确 value/unit，
  禁止隐式 ms、mH 或度/弧度换算。旧版本验证和执行保持兼容。
- 外部资源由可信宿主提供根目录，仅允许固定资产 ID，加载前核对原始 XML、
  磁图与网格的固定 Git blob hash。实验输入本身不能选择任意本地文件。
- 同一 CLI、Python API 和受限 Agent 工具运行现有后端；结果统一为带单位、
  时间语义的信号流、固定指标、输入/原始数据 hash、后端与参数来源。
- 控制采样包含真实首末样本；事件流允许重复时刻但不得倒序。宏步为整数控制拍。
  程序验证运行预算、模型/后端能力组合，拒绝静默忽略不支持的设置。

## 控制优化与分析

原 robot-elastic 基准在 0.25 s 窗口的位置尾段误差约 0.0376 rad，目标 0.03 rad。
保留目标、轨迹、时长、物理参数和电流环预算，仅调位置 PD 的 Kp/Kd。
定义 tau*=Kp*(qref-q)-Kd*qdot+模型偏置，现有设置 Kp=150 N*m/rad、
Kd=20 N*m*s/rad；搜索 Kp ∈ [50,1200]、Kd ∈ [5,100]。

- python-control 0.10.2：线性化双惯量+一阶电流环，用于极点/频率响应和解释；
  它不替代开关/机器人验证。与独立一阶解析阶跃误差 < 1e-8。
- Optuna 4.5.0：固定种子、有界预算的优化提议；训练使用明确标注的平均电压
  联合模型，再用原开关/死区高细节模型验证。冻结验收器，保留全部失败提议。
- SALib 1.5.2：Morris 筛选刚度、惯量、电流环带宽的敏感性。
  先对独立线性函数 f=x0+10*x1 验证效应 1/10，误差 < 1e-9；
  本项目筛选基于标注的降阶模型，不称为高细节模型不确定度。
- 最多 8 次初始训练提议；高细节验证基准、齿隙和新增 0.5 kg 工具负载。
  负载留出工况不参与训练。固定位置尾段平均绝对误差 <=0.03 rad；
  研究电流峰值 <=20 A、传动转矩绝对峰值 <=100 N*m，各项独立报告。
  若未达标，继续在预先范围内改进设计，不能改目标或抹掉失败结果。

## 固定验收

1. 旧测试及 IR 0.1 运行保持通过；0.2 四类后端使用同一运行/结果校验器。
2. 错误单位、超预算、不支持的配置、资产篡改、缺失/倒序时间和目标改写被拒绝。
3. Agent 验收只重算受信任原始信号，不信任结果中自报的 metrics/passed。
4. 原生端点与直接模型运行一致，差异 < 1e-12；同配置/种子的重复结果 hash 一致。
5. 原始基准与优化后完整保留，训练/留出、高低保真明确标识。
6. HTML/PDF 中增加优化轨迹、基准/改进对照、留出结果、线性分析和敏感性；
   浏览器检查新增交互、导出和 390 px 布局。
