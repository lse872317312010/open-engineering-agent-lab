本批连续完成实际带载角度留出、异常转矩的网格复核、三次继续角步减半、角度相关磁链动态接口、20 kHz PI/平均SVPWM及统一交互报告。原公开SPMSM_001、材料、50mm叠长、坐标、峰值电流和固定局部电感保持，仿真不要求真机。

## 首级发现：绝对转矩不能由粗角代表

四个机械角中点和45°闭合端点各四个电流（零流、(0,2)、(1,1)、(−1,1)A）新增20个真实FEMM静磁解，重验复用先前16个粗角细网格解。11.25°实际端点线性插值在5.625°中点的磁链向量最大差/0.05Wb为0.0104241，低于0.02预算；但**绝对转矩最大差1.937323Nm，超过0.10Nm预算，首级角步比较失败**。最大差位于16.875°、(0,2)A：实际转子应力转矩约1.963965Nm，粗角线性插值约0.026642Nm。

差异主要体现于零电流下随角度变化的绝对转矩。相同四电流中，各角扣除同角零流基准后的转矩增量插值最大差为0.030773Nm；固定局部模型对36个指定场点的最大磁链差/0.05Wb为0.00771812，最大增量转矩差0.0337501Nm，均在各自既定预算内。**先前通过的是扣除零流的增量比较，不足以证明绝对转矩或波动可由粗角表示。** 不把两类指标合并。

45°实测端点与0°的零流磁链向量差0.185954μWb、绝对转矩差0.000544799Nm；二者分别列出，未用周期复制替代原生解。原生转子/气隙应力结果分别保留。

## 中间角网格复核

针对四个中间角，新增零流/+2A共8个中档K=1.5场，与各自实际细档K=2逐点核验。8点均满足原预算：最大磁链向量差/0.05Wb为0.00142736，最大绝对转矩差0.00221924Nm，最大同网格零流扣除增量差0.000736060Nm。细网格转子/气隙应力两种结果同时保留。

这说明所选两档网格间差异相对于粗角插值超差较小；它**不证明真实齿槽转矩幅值或独立物理精度**，不替代材料实测、独立求解器和更全面的网格/时间收敛。

## 角度相关接口与20 kHz电流环

由粗角零流dq磁链建立分段线性ψ(θ)，沿用固定对称正定2×2 L，λ=ψ(θ)+Li；周期边界以0°替代实测45°的ψ，修正量和原始差保留，新的密集角点没有反向重拟合。区间内部：
`v = Ri + L di/dt + ωm ∂ψ/∂θm + 4ωm Jλ`。
增量磁共能、机械转矩及源/铜/轴/磁储能账按同一模型推导，固定定子电流下以独立有限差分检验磁共能角梯度；节点处按运动方向的积分区间采用一侧导数。

先在±300rpm、指定dq电压及R=0.3Ω下比较RK4与独立增广矩阵指数重放、半步长和能量余额：两方向通过预定1e−5A/1e−5J预算。然后接入原20kHz PI、平均SVPWM和静止坐标保持电压，实际位置相关前馈及完整L参与计算。正反转48V各500次命令、501端点，正转另以半步重跑：稳定窗口最大q误差约0.0004015A、最大|id|约0.003207A；最大矩阵指数重放差约3.03e−13A、闭环半步差约5.09e−14A、最大能量余额约1.27e−13J。6V欠压在约0.6025ms积分阶段越出|id|+|iq|≤2A，保留13条命令、14个有效端点及拒绝记录，不裁剪继续。

这些小数值误差说明**该合成接口自身的离散积分与能量账**，不代表真实电机动态精度。速度和dq/母线条件由外部指定，控制使用平均SVPWM；接口不包含零电流齿槽共能/绝对转矩、机械ODE、PWM纹波或损耗映射，不能用其通过状态推断真实转矩脉动。动态ψ只使用粗角零流训练点；中间角及其余密集点未参与重新拟合。
