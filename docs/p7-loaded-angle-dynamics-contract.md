# 带载角步细化与可回归动态接口：先行契约

日期2026-11-05。连续推进：实际带载角度中点、角步比较、冻结模型与角度相关接口、独立数值/能量回归和离线交互报告。相互依赖的门槛分开判定；不以上游静磁通过冒充动态物理精度，真机由用户负责。

## 真实场矩阵与来源

同一公开SPMSM_001、原材料和绕组、PYLEECAN/FEMM版本、50mm叠长、Kgeo/Kmesh=2、冻结dq零位；机械角相对π/8，电角=4θ+δ，电流峰值。每角使用(id,iq)=(0,0)、(0,2)、(1,1)、(−1,1)A，零流FE转矩为同角基准。

旧角0、11.25、22.5、33.75°的16个细网格场经完整原始文件、生产源码、相电流及零位验证后复用；新增5.625、16.875、28.125、39.375°中点各4场，45°闭合端点4场，共20个新解。总9角×4工况=36个静磁场。45°端点真实求解，不用周期复制冒充原生场。

## 角步与冻结模型

先固定粗步长11.25°、细步长5.625°；比较粗网格线性插值在四个真实中点的dq磁链向量与绝对转矩差，归一化基准0.05Wb，预算分别≤0.02及≤0.10Nm。零流、单轴和两混合点分列；细场与粗插值之差不等同真实误差界。模型冻结不重新拟合，按已有1mWb磁链和0.10Nm同角零流扣除转矩增量预算逐点检查。比较端点0°/45°也保留实测差，不能假定完全相等。未达标时报告失败数值，不修改阈值。

## 角度相关动态接口：合成模型，不冒充时步FE

从粗角的零流dq磁链构建分段线性ψ(θ)，L采用既有对称正定固定矩阵，λ(θ,i)=ψ(θ)+Li。闭合端点采用实测0°值以满足45°周期，实际45°−0°差必须先单列；端点取值为模型边界处理，不更改原生数据。ψ的粗角中点不参与插值拟合，使用真实FE零流中点留出比较；角外周期延拓为建模假设而非实测保证。i输入严格满足|id|+|iq|≤2A。

在区间内部，J=[[0,−1],[1,0]]，θm为机械角、ωe=4ωm：
v=Ri+L di/dt+ωm ∂ψ/∂θm+ωe Jλ。
以磁共能相对于零电流为1.5(ψ·i+½iᵀLi)，机械转矩增量为1.5[ωe/ωm iᵀJλ+iᵀ∂ψ/∂θm]，ωm=0时采用连续极限。共能不含零流齿槽能量，因此增量转矩不等于绝对FE转矩。储能增量1.5×½iᵀLi；能量账包括源、铜及上述转矩乘ωm。分段导数在节点跳变，必须以明确的一侧约定及分段积分处理，不将数值切换当真实磁通不连续。

使用固定角速±300rpm、R=.3Ω、可审查确定电压或现有控制器，分别与独立积分参照及半时间步比较；记录角度、电流、各功率和累计能量。接口超出电流菱形或非有限输入应明确拒绝，不裁剪继续。先编写解析极限（常量ψ退化已有旋转模型、零电阻/零速RL、势能梯度及域外拒绝）和事前预算：电流差≤1e−5A、能量余额≤1e−5J；若无法达到则保留失败，不放宽。
