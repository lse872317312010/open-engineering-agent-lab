# 绕组铜耗空间源接口：冻结契约

2026-11-06。承接跨周期机械实验，推进P7-C的损耗空间接口，不改变电机或热求解器。
输入为固定报告的公开PYLEECAN二维绕组多边形和50mm物理叠长，
以及四组跨周期轨迹中实际积分的copper_j。电阻0.3Ω仍为合成指定值。

只取24个Stator-0_Winding区域，按鞋带公式计算截面积，乘0.05m得到体积。
假设铜耗全部均匀沉积在这些**整个槽内绕组区域**：
q=Pcu/sum(V)，每区功率qVi。不是铜填充因子或裸铜体积模型；
未分离端部电阻，暂将其等效放在槽内，不宣称实际局部发热分布。
铁耗、磁体损耗、器件损耗、摩擦均不作为铜耗重复输入。

轨迹必须为1001个连续50µs端点；每50个间隔组成2.5ms热窗，
由积分能量差求平均功率，禁止用末点功率替代。共4×20窗×24区域。
窗口和累计分区能量对输入积分差≤1e-12J，体积正值、标签唯一、
绕组面积和已核验独立面积相对差≤0.001；拒绝非有限、负耗散、
漏点、错误时间和重复标签。失败不归一化修复源数据。

独立矩形面积/指定功率与体积加权分配测试；错误体积、标签、能量和时钟反例。
输出完整区域体积/热源CSV、逐窗能量审计及输入与生产脚本SHA。
此接口不产生温度，不代表热边界、材料、网格收敛或整体Gate C完成。
