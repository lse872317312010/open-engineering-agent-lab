# 机器人中点转矩预测与公平积分器对照：实现前契约

2026-10-24。基线 main：3ea7f3a36fa3501a26cca1d3f94ab5051d9a074a。
遵循仿真交付范围，真机由用户负责；延续能量局部与机器人接口分开审计。

## 问题与本轮范围

现有 Jacobi 零阶保持在 200 / 100 / 50 μs 的接口余额峰值约
0.003934 / 0.001959 / 0.000978 J。不能把这些误差转移成发热或改写余额公式。
新增可选 `coupling_method=midpoint_predictor` 及明确的
`robot_integrator=rk4`；原 `jacobi` / `implicitfast` 仍为默认。
积分器来自现有 MuJoCo，不重写机器人求解器；电磁积分仍使用现有上游模型。

新预测模式首版要求 energy_consistent=true、无夹具、无齿隙和 RK4。
接触/约束激活、预测跨过零挠度或无法找到一致分支时，回退为原转矩规则并记录。
固定验证用例要求没有回退，未覆盖事件不能冒充已通过高阶守恒。

## 中点预测方程与单位

输出侧相对挠度 δ = θmotor/N - (q-q0)，相对速度 v = ωmotor/N - qdot。
N=50；电机输出侧惯量 Jm*N²；机器人有效逆惯量 g=(M^-1)[j,j]，
使用 MuJoCo 的实际完整质量矩阵，包含上游 armature，不用 M[j,j] 代替有效惯量。

令自由相对加速度 a0 =
(tau_e - B*ωmotor)/(Jm*N) - (qacc_j - g*tau_applied_j)，
相对逆惯量 c = 1/(Jm*N²) + g。候选保持转矩 T 下：

- vm = v + h/2*(a0-c*T)
- δm = δ + h/2*vm
- T = transmission(δm, vm)，沿用现有 Kelvin–Voigt 单侧裁剪物理规则。
- 在未裁剪的正支路，T =
  [K*(δ+h*v/2+h²*a0/4-backlash)+D*(v+h*a0/2)] /
  [1+c*(K*h²/4+D*h/2)]；负支路相应改为 +backlash。
  同时检查零转矩分支，逐个验证原力律残差。
- 阻尼热从预测中点的原物理力律计算，保持一宏步；
  不从能量余额反算热量。弹性储能始终用实际端点挠度计算。

δ 为 rad，v 为 rad/s，a0 为 rad/s²，T 为 N*m，c 为 1/(kg*m²)；
K 为 N*m/rad，D 为 N*m*s/rad，h 为 s。

这只是使用冻结自由加速度的模型预测，不是非线性全系统隐式中点求解器。
实际误差与阶数由独立参考和完整联合仿真报告。

## 先行参考与固定验收

1. 先增加纯函数、手算转矩、力律裁剪/回退、孤立双惯量能量恒等式，
   再修改实际机器人耦合。线性双惯量参考用独立矩阵指数：
   减半步长的状态误差比例在 [3.8,4.2]；能量恒等式误差 <1e-10 J。
2. 旧 66 项回归及五配置 IR/CLI、ARM/SIL、原控制优化与八组能量审计保持有效。
3. 同一 RK4 积分器、同一物理参数/控制器/轨迹下比较 Jacobi 与预测模式：
   40 ms / +0.008 rad，宏步 200 / 100 / 50 μs。
   200 μs 的接口峰值和扩展余额峰值均至少降低 75%；
   50 μs 预测接口峰值 <= 0.4 * 200 μs 预测峰值。
4. 200 μs 增加独立 +0.5 kg 载荷留出和 250 ms / +0.08 rad 轨迹对照。
   两组预测接口与扩展余额峰值均至少降低 75%；固定位置目标 0.03 rad、
   电流峰值 20 A、轴转矩峰值 100 N*m 保持不变。
   长轨迹使用固定的已选 Kp=779.266681952671、Kd=56.608067569927684，
   不重新优化控制器以掩盖耦合误差。
5. 原 implicitfast + Jacobi 单独保留作交叉对照，不把积分器变化算作预测器贡献。
   各工况均通过既有局部能量固定门槛；实际端点储能与原始关节状态独立核对。
6. 新增 `coupling` 宏步原始流：实际/预测挠度与速度、自由加速度、有效惯量、
   保持转矩、力律残差与回退标志；单位、首末点、模式/积分器和来源必须可追溯。
7. 报告新增同积分器误差对照、步长收敛、长轨迹/载荷验证、预测器状态和 CSV，
   浏览器检查离线、时间首末点、390 px、导出及模式边界说明。

## 实现修正前补充：处理可积分分支与 PWM 相位（固定门槛不变）

初版验证 [run 40061839899](https://github.com/lse872317312010/open-engineering-agent-lab/actions/runs/40061839899)
记录：同 RK4 的 200 μs 接口峰值由 0.00393857 J 降为 7.611e-6 J，
但长轨迹有两次跨零回退；50/200 μs 接口峰值比约 0.474，高于固定 0.4。
这些结果保留为失败，不能当成已通过新模式。75%、0.4、零未解决回退和原物理门槛不变。

在修改实现前增加以下物理/数值机制：

- 对可解析的原传动力律，沿预测线性路径 δ(s)=δn+s*h*vm，
  在零挠度、齿隙边界及力律裁剪零点处分段。各段用内点 Gauss 两点积分，
  分别积分原力和原耗散功率，得到宏步平均力与热；不从能量残差反算热量。
  对固定 vm，这些被积函数分段线性，独立能量恒等式应满足原 1e-10 J 门槛。
- 平均力满足同一冻结加速度闭式关系 vm=v+h/2*(a0-c*T)。
  先检查解析候选，再用有界单调括区间求根，最多 80 次二分。
  能解析并通过原力律积分残差的跨零事件标为“已解析分段”，单独记录；
  激活约束、非有限量或无法解决的事件仍回退并使认证失败。
- 新增电磁转矩时间积分状态，单位 N*m*s，只用于预测模式。
  预测器因果读取已完成宏步的真实转矩均值：
  两个历史窗口时预测下一窗口均值为 2*最近均值-前一均值，
  只有一个窗口时使用该均值，t=0 使用实际瞬时转矩。
  不读取未来状态，不改变电流控制目标、PWM、源功率或能量余额。
- 同时保留瞬时转矩、历史均值、预测均值、历史窗口数、转矩积分与已解析分段标志，
  以区分 PWM 相位取样、预测和实际端口。这里的标量迭代只解冻结预测，
  仍不表示非线性子系统回滚或隐式全系统耦合。

先新增分段积分/跨零耗散、因果均值以及原独立收敛参考的测试，再接入真实模型。
原点中点函数和其回退测试保留，作为适用范围有限的独立参考。
