# 关节 FMI 端口与时钟契约（实现前冻结）
日期：2026-10-26。路线图队列 4 的首个完整电气—双惯量—三节点热**研究级植物模型** FMU；
不包含控制器、MuJoCo、六轴机器人、开关器件或 OpenModelica 导出。
采用本仓库 MIT 原创 C 方程；复用 FMPy 0.3.26（BSD-2-Clause 与其随附 FMI 通知）
进行 FMI 2.0 CoSimulation 加载、XML 校验和运行，不复制未核验第三方模型。

## 方程、单位与端口
幅值不变转子 dq：we=7*wm，R=.3*(1+.00393*(Tw-25))，
did=(vd-R*id+we*.0008*iq)/.0008，
diq=(vq-R*iq-we*(.0008*id+.03))/.0008，Te=1.5*7*.03*iq。
双惯量：delta=theta_m/10-theta_l，vdelta=wm/10-wl，Ts=80*delta+.15*vdelta。
Jm=5e-5，Jl=.02；dwm=(Te-Ts/10-1e-5*wm)/Jm，
dwl=(Ts-Tload-.02*wl)/Jl。角度 rad、速度 rad/s、电流 A、电压 V、转矩 N*m。

三个热节点热容为 [60,200,25] J/K，热阻 Rwc=.8、Rca=2、Rbc=1.2、
Rba=4 K/W，环境 25 degC。Pw=1.5*R*(id²+iq²)，
Pf=1e-5*wm²+.02*wl²+.15*vdelta²。
dTw=(Pw-(Tw-Tc)/.8)/60，
dTc=((Tw-Tc)/.8+(Tb-Tc)/1.2+Pf-(Tc-25)/2)/200，
dTb=(Pboard-(Tb-Tc)/1.2-(Tb-25)/4)/25。
Pboard 是外部供电的附加板级热输入，不是重复计入铜耗或已识别的开关损耗。

输入 vd、vq、Tload、Pboard；电压矢量<=48/sqrt(3) V，|Tload|<=10 N*m，
0<=Pboard<=1000 W。输出九状态、三个累计能量与轴转矩。
正载荷转矩从正转轴吸取功率，也可在反转时向系统供能。
三能量积分：Ein'=1.5*(vd*id+vq*iq)+Pboard，
Eload'=Tload*wl，Eambient'=(Tc-25)/2+(Tb-25)/4。
储能 E=.75*.0008*(id²+iq²)+.5*Jm*wm²+.5*Jl*wl²+
.5*80*delta²+60*(Tw-25)+200*(Tc-25)+25*(Tb-25)。
独立余额 E-E0-Ein+Eload+Eambient，不能当作热源。
热初始25 degC，其余初始零；本版物理参数固定合成研究值并随包留存。

## 时钟与生命周期
主机先读输出、计算/写输入，再 doStep(t,h)，输入在整个通信窗零阶保持。
这里**在旋转 dq 坐标保持电压**；不等同于既有静止 alpha/beta PWM 保持。
20 kHz 示例 h=50 us；允许变通信步长 0<h<=1 ms；内部 RK4 子步<=5 us，
内部步长参数在初始化前可减小，运行时不可修改。
不支持回滚、序列化状态、异步执行、导数插值或 FMI 3.0 clocks；
通信点检查和 ZOH 排程是 FMI 2.0 下明确的主机契约。
setup -> enterInitialization -> exitInitialization -> doStep -> terminate；
reset 回到实例化初值。错误生命周期、时钟、越界写、NaN/Inf、
输出写入、超停止时间与非法步长必须报错且不改状态。
批量 setReal 与整步 doStep 均采用事务式验证后提交。

## 实现前独立参考与固定 Gate
1. SciPy DOP853 由单独 Python 方程实现，逐个相同 ZOH 窗积分；
   所有九状态采样点最大绝对差<=2e-5（按各自 SI 单位）。
2. 四个固定 .08 s 场景：空载正向、带载/板热、转向变化、变通信步长。
   不使用这些场景整定参数。所有输出有限；余额峰值<=2e-6 J。
3. 5/2.5 us 内步比较使用同一输入时序，末态差<=2e-5，
   细步参考误差<=1.2*粗步误差+1e-10（允许浮点噪声）。
4. 无激励平衡必须保持；稳态 RL 极限及纯板热初始斜率提供独立点参考。
5. lifecycle、原子非法写、非连续时钟、超步长、停止时间、初始化后参数写、
   reset 重现、两个实例隔离及非法 GUID 测试通过。
6. 保留 CSV、输入、源代码/环境/二进制哈希、FMU、失败结果；
   离线图表/状态回放可选场景、键盘定位、390px 布局与无外网请求经真实浏览器检查。
