# MSL 六节点热 FMU 与一小时交换验收（实现前冻结）

日期：2026-10-27。路线图队列4继续复用成熟开源物理组件，
不改旧七配置、九状态关节或既有热网络默认行为。真机由用户负责。

## 模型与来源
使用Modelica Standard Library 4.0.0的真实HeatCapacitor、ThermalResistor、
PrescribedHeatFlow、FixedTemperature组件，通过connect连接组成六节点网络，
不能以手写同一ODE冒充MSL组件采用。
MSL v4.0.0标签解析为6626538a236a34a390655b55d5e8c906bfe31772，
BSD3-Clause许可先核验归档。编译器沿用已经验证的OpenModelica1.25.5不可变镜像。
模型内部绝对温度K，输出明确换算摄氏度，温差K；热源W、储能J。
六节点顺序：winding/core/case/junction/board/sink。
C=[60,70,200,.5,25,100] J/K；
节点间(a,b,R)：(0,1,.6),(1,2,.4),(2,4,2),(3,4,.8),(4,5,1.2)，R单位K/W。
壳体(2)->环境R=2，散热器(5)->环境R=3。
六个非负独立损耗输入，ambient_k为初始化前固定参数263.15..333.15K。
六热状态+输入能量与散热能量积分，共8连续状态；初温均为环境，能量账初始0。

独立方程（非MSL实现）：Qab=(Ta-Tb)/Rab；
Ci*dTi=Pi-ΣQout；Qambient=(Tcase-Tenv)/2+(Tsink-Tenv)/3。
Ein'=ΣPi，Eambient'=Qambient。
余额=ΣCi*(Ti-Tenv)-Ein+Eambient；不得由自报余额或错误C/K换算替代。
额外输出五条内部有符号热流和环境总热流；有符号方向以边表a->b为正。

## 实现前固定输入
六个一小时场景：ambient_c=-10/25/60，各通信周期1/.5s。
按现有热耐久BLOCKS，依次：
600s:[40,5,0,15,0,0]W；
1200s:[10,2,0,3,0,0]W；
600s:[60,8,0,20,0,0]W；
1200s:[0,0,0,0,0,0]W。
每个通信窗严格ZOH；到块边界必须精确分段，不插值跨越热源跳变。
CSV保留全部3601或7201状态端点，输入列表示该端点之前通信窗的实际保持输入，
初点输入为0；回放/比较也使用此语义。不是一小时电机/整机连续联合运行。

## 独立参考与固定Gate
先提交本契约及独立手算/极限参考，再写MSL模型和主机。
导出的FMI2 ModelExchange由FMPy实际加载；此模型无事件，
主机DOP853逐窗积分生成导数。不是通用事件驱动FMU主机。
参考1：独立物理端口方程Radau，逐块dense输出完整共同时间点；
参考2：现有原生ThermalNetwork矩阵指数逐窗推进。不能只比较四个块末点。

六组所有节点/端点与两路参考最大差各<=2e-7K；
独立储能与实际积分账余额峰值<=1e-5J；
实际积分账与Radau对应能量差各<=1e-5J；
五内部热流/环境热流按真实温度重算差<=2e-7W；
所有温度>=环境-1e-9K，有限、时间严格递增。
1/.5s全轨迹共同点最大温差<=2e-7K。
初始化K/C转换、零激励平衡、纯结温热源初始.5W/.5J/K=1K/s、
独立实例、reset重现均另验。
给能量副本增加10J必须被固定余额门槛拒绝。
以上验证指定合成参数与热源，不证明器件热额定值或未知工况。
