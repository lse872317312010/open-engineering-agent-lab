# FMI 统一实验与外部电流主机契约（实现前冻结）
日期 2026-10-26。继 PR #18 的固定九状态植物，增加 IR 0.2 第六配置 fmi_joint_v1，
backend=fmi。复用 FMPy 0.3.26 和既有受保护电流 PI；不修改 C 植物方程。

## 固定范围与主机时序
物理参数与 joint-fmi-contract.md 相同，参数覆盖拒绝；
控制器使用名义 R=.3、Ld=Lq=.0008、psi=.03、pp=7。
每 50 us 读 FMU 九状态 -> 生成 0 到目标电流阶跃 -> 径向电流参考限幅 ->
按既有 CurrentPI 核心更新积分/抗饱和 -> 名义反电势解耦 ->
可选一采样电压延迟 -> 写旋转 dq 电压/恒定负载/恒定板热 -> 推进窗口。
主机将每个 50 us 控制保持窗细分为 <=integration_step_s 的 doStep；
每次只采样植物、不再计算控制，因此能保留真实内部 RK4 端点波形。
这里 FMI 调用步长与控制采样周期显式分开，都是实际记录的时钟。
终点只记录先前保持命令，不额外计算控制或推进积分。
电流环闭环不等于位置控制或包含 PWM 的完整 FOC。
内部 RK4 最大步长 10 ns..5 us，控制周期固定 50 us，母线0<Vdc<=48 V，
载荷绝对值<=10 N*m、板热0..1000 W。积分预算由实际 ceil 子步精确核算（每 RK4 子步含末态域检查共 5 次 RHS）；
所有有效时钟和预算在 FMU/可选库加载前检查。

## 实现前固定案例与 Gate
四组 .06 s / 50 us：nominal iq=1 A、reverse iq=-1 A、
loaded-board iq=1 A/恒载 .2 N*m/板热20 W、
delayed iq=1 A/一采样延迟。阶跃 .005 s，带宽/追踪1000 s^-1，母线48 V。
不对该组工况搜索或重新整定。
四组尾段 q 电流误差<=.1 A，真实矢量电流峰值<=3 A，实际轴转矩峰值<=10 N*m，
全域独立余额峰值<=2e-6 J。
单独不可达案例：Vdc=2 V、iq=5 A、时长 .06 s，
沿用同样 .1 A 尾差门槛，必须明确失败并保留数据。
DOP853 独立逐窗重放实际已施加 dq 电压，九状态逐项误差<=2e-5 SI单位，
并以其每窗初始状态单独重建 PI 指令（允许累计误差<=2e-5 V）。
固定输入重运行原始流散列一致；CLI/API 和受保护工具结果一致。
原五配置、Ruff/pytest、完整统一报告回归保持。
新报告需显示主机/植物边界、电压饱和、延迟、真实峰值和明确失败案例，
支持场景切换/状态回放/完整CSV/PDF，桌面及390px真实浏览器验证。
