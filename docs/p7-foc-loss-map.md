# 固定转速FOC周期铜耗表

2026-11-08。[先行契约](p7-foc-loss-map-contract.md)先提交为3164c154。
复用既有静磁衍生电磁模型与20kHz PI/48V平均SVPWM，
在固定机械速度及参考电流下得到实际周期铜耗，再冻结电阻插值表。
它为长时热模型补充有留出检查的电气损耗输入，不改变原静磁模型或热基。

外部机械主机规定θ=θ0+ωt，|ω|=39.269908…rad/s，机型周期恰为20ms/400个控制tick。
iq参考为随转向取±0.5A、id为0，PI增益固定在25°C参考电阻。
T=25/75/125°C、两个方向共6个建表工况，各300ms；前200ms消除初始暂态，
最后5个完整周期的铜耗积分/总时长作为均值。
T=50/100°C、两个方向共4个留出工况，初角从训练0.1rad改为0.17rad，不参与插值表生成。

新推进器利用固定R/ω下电气方程的线性结构：电流、旋转电压、常量和6组磁链谐波
组成17状态系统，矩阵指数推进；三个二次型精确积分输入电能、铜耗及电磁轴功。
控制器仍按50µs更新，电压在静止αβ坐标中保持，每5µs检查电流域。
磁储能与原CoggingMotor.stored交叉检查，功率形式核验储能导数恒等式。
独立RL解析电流/热损及一个留出的DOP853回放分别验证通用积分与完整电磁模型。

锁速能量账为：输入电能−铜耗−电磁轴功−磁储能变化。
电磁轴功包括齿槽共能贡献，由锁速外部机械主机承接；本试验不积分自由机械ODE。
原50ms反馈专项约±40rad/s初速的自由机械工况与当前锁速39.27rad/s工况不同，
不能把两组损耗差异全部归因于启动，或把某个短窗偏差直接外推至数小时。

训练和验证分进程。冻结包包含两个方向的三点Pmean(R)，由NumPy线性插值推理；
严格支持R=0.3–0.42Ω、当前固定速度幅值与±0.5A参考，超域拒绝，不外推。
运行时支持将预测窗能送入严格StatorCopperFeedback接口，温度更新后用于下一窗。
独立两节点手算与非法调用不改热状态检查保留。

热应用为环境25/75°C×正反转，h=8，分别以周期均值表及原理想恒流源驱动冻结ROM
至24,000s。两种模型各自闭环计算自己的温度、电阻与热源，并记录模型间温差。
这个差异不是已知真实温度误差；长时电气仍采用冻结的周期均值模型，省略启动和转速变化。

先完成原P7源、热FE及两版ROM验证，再分别运行：

```bash
python benchmarks/p7_foc_loss_map.py train
python benchmarks/p7_foc_loss_map.py validate
```

outputs/p7-foc-loss-map/保存训练/留出控制CSV、静止电压命令、周期能量、DOP853轨迹、
冻结推理包与SHA、四组热应用NPZ、图、summary与manifest。
原始CSV列见p7_locked_electrical.COLUMNS；控制行电压为该周期施加的起点dq值，
末行仅为轨迹终点，电压按最后保持的静止命令在末端角度重新投影。
热应用values轴0为映射损耗、轴1为理想恒流；列为四热输出、R、窗功率、源能、散热、余额。

本地数值结果：4个留出最大相对插值差约7.05e-8（0.00000705%，预算0.5%）；
DOP853电流差约6.47e-13A，三个累计能量差≤1.90e-13J；
全部10例能量余额≤7.77e-14J，无电压或参考限幅。
周期均值与理想恒流铜耗的最大相对差约0.00301%，并未把原50ms短窗的约3%差异当作周期修正量。
4条24,000s热应用中，两种模型的最大均温差约29.93µK，热能余额≤7.72e-10J。
这些是当前同一电磁/热模型下的数值结果及模型间差异，不是实物损耗或温度精度。
