# P7 固定转速FOC周期铜耗表契约

2026-11-08，执行前固定，承接#69。已有长时模型采用理想恒流，
本增量用实际20kHz PI/48V平均SVPWM电气解建立周期均值铜耗表。
机械角由外部锁速主机规定，θ=θ0+ωt，不积分机械ODE；电磁轴功单列。

固定|ω|=(π/4)/0.02=39.269908…rad/s，每个机型周期恰为400个控制周期。
iq参考随方向取±0.5A，id=0；PI增益仍以R25=0.3Ω固定，不随电阻调参。
训练θ0=0.1rad、T=25/75/125°C对应R=0.3/0.36/0.42Ω，正反转共6例。
每例15个20ms周期；前10周期消除初始暂态，最后5周期计均值。
线性插值Pmean(R)，训练完成冻结表、源码、控制器及电磁模型SHA。
独立验证θ0=0.17rad、T=50/100°C，正反转共4例，不参与建表或选阶。

电气在固定R、ω和每控制周期静止αβ电压下为线性、有限Fourier受迫系统。
将旋转电压、常量、6组磁链谐波加入状态，使用矩阵指数推进并积分二次功率。
每5µs检查电流域，电流/控制/能量原始轨迹保留。独立RL解析能量检查和
一个50°C正转留出最后5周期的DOP853回放核验新推进器。
机械锁速下能量账为输入电能−铜耗−电磁轴功−磁储能变化，不把固定速度解释为自由机械联动。

所有10例：无电压/参考限幅，电流L1≤2A；最后两个周期相位对齐电流差≤1e-5A，
最后5周期铜耗相对极差≤1e-4；全部能量余额≤1e-8J。
四个留出均值对冻结线性插值：相对铜耗差≤0.5%。
DOP853同命令、同固定R/ω回放的电流端点差≤1e-6A，三个累计能量差≤1e-8J。
保留理想0.5A恒流铜耗与实际周期均值的偏差，不以缩小该偏差作为拟合目标。

推理只需NumPy。严格只支持冻结电阻区间、当前固定转速幅值与参考电流，
超温对应电阻、错误速度、错误电流参考、非有限参数和篡改包拒绝；禁止外推或夹紧。
训练与验证分进程，不修改既有热ROM、功率上界或旧验收。
