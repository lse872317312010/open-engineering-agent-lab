# 十二参数辨识的噪声、输入误差与不可辨识边界（实现前冻结）

日期：2026-10-29。前置：PR #28 六温度/六已知热源的 MSL 合成辨识。
本实验不修改物理模型、拟合器、原固定门槛或上一轮结果。证据等级 model_simulated。

## 问题与固定输入

单个种子、0.02 K 白噪声的成功不代表稀疏观测、传感器偏置或未知热源下可用。
复用上一轮实际 MSL 生成协议，每次工作流重新导出固定 FMU 并生成三个独立数据集。
训练 1200 s、0.05 s 网格；留出 300 s、60°C，输入不同；全部参数和热源来自
msl_identification_protocol.py。原始训练温度无噪声 CSV 只由数据生成进程访问。

预先定义共 20 个训练包：
- 无噪声 1 组；
- 0.02 / 0.10 / 0.50 K 独立逐温度逐采样 Gaussian 白噪声，
  每档 4 个固定种子 2026102901–2026102904，共 12 组；
- 默认 0.02 K / 种子 2026102901，另加绕组 +2 K、全部温度 +2 K、
  全部已知功率记录乘 0.5、绕组功率记录置零，各 1 组；
- core 温度缺失（NaN）、恒温零输入无噪声、恒温零输入 0.02 K 噪声，各 1 组。
故障按单项注入，不混合。恒温包与实际 MSL 激励数据不同，是故意合成的退化测试。
缺失通道应明确拒绝；本轮不插值，也不实现稀疏观测辨识。

## 流程与隔离

生成器只输出观测训练包和公开 ambient/area/Gc、案例说明。
独立拟合进程仅打开这些训练 CSV / public.json，不导入协议真值或读取验证/留出。
每组保留成功/异常、12 个参数、rank/condition/残差/bound，参数 JSON 冻结 SHA256。
独立评价器随后读真值、实际 MSL 留出轨迹，使用原独立 Radau 方程预测。
这是拟合参数的独立方程预测对 MSL 真值；不是逐组新实例 FMU 预测。
上一轮对原拟合的新 FMU/数值/能量 Gate 保留。
所有成功拟合均预测，不因已知参数误差大而省略失败案例。输入/输出 CSV 与哈希完整保存。

## 固定判据

单组“合成适用性通过”需要：拟合成功、无活动边界、参数最大相对误差 <=10%，
留出每节点 RMSE <=0.5 K、全局峰值 <=1.5 K。
该判据使用已知合成真值，**不能当作真实数据在线故障检测器**。
rank 与优化成功只能说明数值问题可解，不保证热源/观测正确。

整套 Gate：案例数20、无噪声和四个0.02 K重复全部合成适用性通过；
core缺失及恒温无噪声明确拒绝；功率减半不得被标成合成适用性通过；
每个返回的参数均有完整300s留出预测、有限结果和冻结哈希校验。
0.10/0.50 K及其余故障的通过率、误差和失败原因按实际记录，不承诺通过。
“整套通过”代表按约运行并识别固定边界，不是20个拟合均正确。

## 数值与报告

沿用已冻结的 SciPy1.15.3 lsq_linear、积分窗口、bounds与秩阈值，不优化门槛。
留出 Radau rtol/atol1e-11；无噪声拟合另以分段DOP853 rtol/atol1e-11
交叉核验温度差 <=2e-6 K。模型有效范围继承原契约。

新增独立解析尺度歧义基准：绝热网络中 (C,G,P) 同乘正数，温度导数不变，
说明仅有温度且热源尺度未知时无法唯一识别绝对参数。先提交该基准再实现实验。
