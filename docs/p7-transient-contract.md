# P7 瞬态有限元：实现前冻结契约

2026-10-30。继有限接触热阻稳态基准，增加一致质量矩阵与时间步进。
当前仍为原创理想参数、二维离散的一维物理场；不声称工程P7-C/P7-D或实测。
复用Gmsh4.13.1/scikit-fem11.0.0/meshio5.3.5/SciPy1.15.3，无新增依赖。

## 方程、单位、输入和参考职责

两区几何/导热/界面沿用p7-contact：长.1m、高.1m、厚.01m，
分区x=.04m，k1=2、k2=.2 W/(m K)，Rc=.1 m²K/W。
左右环境和左恒温均25°C，初始全场25°C；右h=10 W/(m²K)，上下绝热。
体积热容Cv1=1000、Cv2=2000 J/(m³K)，为便于观察动态的合成值，非材料标定。
Cv dT/dt-div(k grad T)=s(t)，接触qI=(TL-TR)/Rc，无界面储能。
源s1=1000、s2=2000 W/m³乘p(t)，
p(t)=[1-cos(2pi t/8)]/2 (0≤t≤8s)，其后0，运行至16s。
初态源为0，8s严格为时间节点；平滑热脉冲后冷却。

装配一致P1质量矩阵M=厚度∫Cv phi_i phi_j；K复用既有接触弱式。
以u=T-25求解自由节点：M du/dt+K u=f p(t)。
Crank–Nicolson： (M+dt K/2)u_next=(M-dt K/2)u+dt f(p_old+p_next)/2。
空间n8/16/32、时间dt=.2/.1/.05s，九组合，不把dt小称为物理准确。
总容量由独立面积/节点体积分核对为.16J/K。
E区=厚度∫Cv u，每步全局/两区余额分别审计，累计源/散热/接触功率按同一梯形步积分。
左向外功率由包含M du/dt项的恒温反力计算，不能只用稳态反力；
左右区域源积分由三角形面积独立重算，不只从载荷相加。
固定热源积分连续真值总量.64J，离散收支与连续积分误差分开。

独立参考p7_transient_reference.py在实现前同契约提交：
1. 同一FE矩阵的广义对称特征模态+每模态raised-cosine闭式响应，只核对时间误差；
   不宣称独立空间求解器。
2. 完全从几何/材料/边界重建的一维cell-centered有限体积；
   每区512/1024cell，串联半单元导热阻、Rc、边界对流阻；
   用对称三对角特征分解及闭式时间响应，独立于Gmsh/FE矩阵。
   参考在t=2/4/8/12/16s评价，细化差必须先通过。
   仅此y不变基准可与1D参考比较，不能推广复杂2D。

## 实现前固定门槛

- 九组合全局/左右区每步累计能量余额绝对最大≤1e-9J，自由方程残差归一化≤1e-9。
- 三档网格独立几何容量与M行和/节点体积权重相差≤1e-12J/K；
  K/M对称差≤1e-12，错配拒绝保持。故意漏记左边界瞬态容量反力必须导致能量Gate拒绝。
- n8各dt的全时间轨迹对模态参考，M加权时空相对RMS；
  两档时间收敛阶≥1.7，dt=.05误差≤0.2%，全节点最大误差≤.02K。
- 有限体积512→1024每区，五时刻全域温升相对RMS差≤1e-4；
  只有通过才作为空间参考。
- FE每网格用dt=.1/.05的(4*u_fine-u_coarse)/3消去主导二阶时间误差，
  五时刻对1024cell/区参考做全域温升相对RMS；
  网格收敛阶≥1.5，n32误差≤0.5%。该量是Richardson估计，单列实际CN误差，不冒充精确时间解。
- dt=.05的连续源积分最大差≤1e-4J；所有终点源能与.64J相差≤1e-12J。
  各组合16s储能低于8s，8s后源为0且总散热为正。
- n16基准dt=.05与双Cv/双脉冲周期16s/终点32s/dt=.1配对：
  对应时刻温度最大差≤1e-9K，储能及全部累计热量为原值两倍，误差≤1e-9J。
- 归档全部时间步/节点、区域源/热流/储能、矩阵/质量/解、参考与误差/版本/CPU/RSS/命令/散列。
  数据source_kind=synthetic；参考类型分别记录，不能全称为连续解析真值。
