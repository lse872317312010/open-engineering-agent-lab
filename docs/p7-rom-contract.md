# P7 首个FE→ROM：实现前冻结契约

2026-11-02。仅固定二维接触板的合成降阶验证，P7-D部分增量；
不是器件热模型、20kHz FOC联合、物理温度估计或板端硬实时验收。

## 模型、数据与许可

复用已验收n32网格：2178温度节点、33固定左恒温节点，2145自由节点。
u=T−25°C；M du/dt+K u=F a(t)，左右体源是两个独立输入列，
原Cv=1000/2000 J/(m³K)、k=2/.2 W/(m K)、Rc=.1m²K/W、h=10 W/(m²K)。
所有参数合成，环境/左边25°C，初态u=0。主IR和旧FE默认路径不变。

新增可选pyMOR2026.1.1：实际调用质量内积POD和Gram-Schmidt，
SciPy仍负责已有CN时间步进；不宣称整个时间求解由pyMOR实现。
其POD代码BSD-2-Clause，整体项目元数据BSD-2-Clause AND BSD-3-Clause，
同时归档LICENSE.txt与LICENSES_bundled.txt，不按单一BSD2概括全包。
版本/上游tag commit/API方向核验和pip安装来源写入组件评审/证据。

generate/fit/validate三个独立进程：
generate只生成训练及公开全阶矩阵；fit仅读train/目录，
冻结基底、Mr/Kr/Fr及训练文件SHA256后，validate才生成新全阶验证/留出轨迹。
这是代码/文件使用隔离，不冒充操作系统安全沙箱。

训练：两组独立区域源，分别左/右8s raised-cosine脉冲，0–16s，dt=.05s。
POD只用这两组轨迹，最多12个模态，rtol=1e−10；
先放入左右区域自由节点指示向量，再用质量内积正交化POD模态，最终≤14维。
加入区域测试向量是为了Galerkin保持两区能量账，不能只凭POD能量占比宣称物理守恒。
VᵀMV=I，Mr=VᵀMV、Kr=VᵀKV、Fr=VᵀF；重建u≈V z，固定节点仍0。
同一CN规则推进全阶/降阶，数据为合成。

## 冻结评测矩阵与门槛

0–16s，dt=.025s，FOM/ROM使用同一实际输入与初态：
- train-left / train-right：训练形状，作为再现检查，不充当泛化证据。
- validation：左幅1.2/周期6s、右幅.8/周期4s/延迟1s。
- holdout：左幅.6/周期2s/延迟.5s，右幅1.5/周期3s/延迟2s。
  validation与holdout不得用于选模态数、基底或阈值。
- out-of-domain：源与validation相同、实际接触Rc=10，ROM仍冻结Rc=.1。
  参数守卫必须拒绝Rc不匹配；另保存“不守卫仍运行”的反事实错误，不能标为受支持预测。
  不预设反事实必须超过某误差门槛，参数越域本身即拒绝。

同参数四组：全自由节点/全部时刻M加权相对RMS≤1%，
全节点峰值误差≤.05K，两区均温峰误差≤.02K，
界面向右功率峰差/原峰源功率尺度.16W≤5%。
全阶和增强ROM的全局/两区累计能量最大余额≤1e−8J；
时间输入/边界/接触积分与储能按CN区间分别核对。
Mr/Kr必须对称正定，质量正交误差≤1e−9，维数≤14，冻结hash前后不变。
validation和holdout另做FOM dt=.0125s，
相对RMS变化≤.2%、节点峰变化≤.002K，用于限制时间离散误差。

性能单独测试宿主400Hz预算：dt=.0025s，
预计算分解，100步预热、5000实际ROM更新+六项输出样本，记录p50/p95/p99/max与全部样本；
p95≤2.5ms为本宿主预算门槛，最大值另列，不作为硬实时保证。
同输入FOM更新+同六输出至少300样本；全场重建另计至少500样本，
不得把只推进降阶状态称为全场重建/绘图/FOC成本。
记录CPU/线程/内存/预处理成本，不预设加速倍数，也不要求FOM超预算。
