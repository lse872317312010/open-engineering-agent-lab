# ADR 0002：实际采用 motulator 与 MuJoCo/Menagerie 模型

状态：采用；数值验收随工作流证据绑定，所有物理目标独立报告。
日期：2026-10-23。

原生九状态模型适合快速闭环研究，但平均电压、常电感、理想反馈与固定负载
不足以研究开关纹波、饱和、机器人姿态和接触。继续在本地写更多未经对照的
简化方程会增加维护成本，不能替代成熟模型的实际执行。

## 决策

- adopt motulator 的磁链状态电机、非线性磁图、开关/死区、二极管关断事件、
  电容母线、六脉波整流、双惯量、传感器与事件求解。
- adopt MuJoCo 的刚体约束/接触求解与 Menagerie UR5e 质量、质心、惯量和几何。
- adapt OEAL PI、明确的采样/单周期延迟、单关节力矩接口、弹性/单边齿隙、
  研究六节点热网络和可观测报告。
- retain 原生九状态模型作为低成本研究基线，保留原有独立参考。
- 不把上游示例电机与原研究电机混作误差比较；不把上游随包发布的
  测量来源磁图当作用户设备的标定数据。

## 版本、许可与接口

精确提交、哈希和固定验收见 ../p6-open-model-refinement.md。
motulator 为 MIT，MuJoCo 为 Apache-2.0，UR5e 模型为 BSD-3-Clause。
不复制求解器/电机源码；通过可替换的 Python 适配器调用。
上游资产在独立工作流中取得，许可证随证据与报告分发。

电气以复数幅值不变空间矢量和 SI 制交换；电机与机器人以力矩/速度功率端口
作显式宏步耦合，宏步减半检查位置差。关断事件交给上游 AC-port/二极管机制，
不能用零平均电压代替。器件损耗仍为声明的研究估计。

## 影响与限制

高细节仿真执行更慢，使用独立 Python 3.12 工作流，不增加基础运行时依赖。
仅一轴接研究电机，其余机器人轴用上游位置执行器保持；
磁图有域限制，图外结果不作为有效结论。
MOS 寄生/反向恢复、EMI、齿面有限元和真实数据标定不在当前模型范围。
物理目标未达必须显示，数值模型通过不能覆盖它们。
